5 MCP-серверов для Claude Code: что дают и как поставить

Виктор Дачников 17 июня 2026 7 минут

🟡 Средний - нужна базовая настройка Claude Code и понимание основ

⚡ Не обязательно читать всю статью Скопируй ссылку на эту статью и отдай Клоду: «Проведи меня по этой инструкции шаг за шагом». Он прочитает её сам и проведёт по установке, отвечая на твои вопросы по ходу. Если хочешь разобраться сам - читай дальше.

MCP-серверы - это расширения для Claude Code. Поставил один раз и Клод умеет то, чего раньше не мог: открывать браузер, искать в интернете, скрейпить сайты, генерить картинки. Здесь пять серверов из практики с командами установки и честными комментариями про ключи и лимиты.

По умолчанию Claude Code работает только с тем, что есть у тебя на компьютере: файлы, код, терминал. Это уже мощно, но иногда нужно больше. Нужно, чтобы Клод сам погуглил, открыл сайт, скачал контент с чужой страницы или сгенерил картинку прямо в процессе работы.

MCP (Model Context Protocol) - это способ подключить к Клоду внешние инструменты. Поставил сервер, и у Клода появился новый навык. Убрал - навык пропал. Всё через конфиг или одну команду.

Как вообще ставится MCP-сервер

Есть два способа. Первый - через команду в терминале:

bash
claude mcp add <название> -- <команда запуска>

Второй - через конфиг .claude/mcp.json в папке проекта или в ~/.claude/mcp.json глобально:

json
{
  "mcpServers": {
    "название": {
      "command": "npx",
      "args": ["-y", "@пакет/mcp@latest"],
      "env": {
        "API_KEY": "твой-ключ"
      }
    }
  }
}

Проверить что серверы подключены:

bash
claude mcp list

Для большинства серверов нужен Node.js. Если его ещё нет - скачай с nodejs.org, выбери LTS-версию.

Теперь по каждому серверу.

1. Perplexity MCP - живой поиск в интернете

Что даёт. Клод начинает искать актуальную информацию в интернете прямо во время работы. Спросил «что нового в Claude 3.7» или «какая сейчас цена на Figma» - Клод сходит в Perplexity и вернётся с ответом, а не с «я не знаю, мои данные устарели».

Это особенно полезно для ресёрча, проверки актуальных цен, поиска документации по свежим библиотекам.

Установка. Нужен API-ключ Perplexity. Бесплатный тир есть, но с лимитами - хватает для нечастого использования.

Получить ключ: perplexity.ai/settings/api

bash
claude mcp add perplexity -- env PERPLEXITY_API_KEY=твой-ключ npx -y @modelcontextprotocol/server-perplexity-ask

Или через конфиг:

json
{
  "mcpServers": {
    "perplexity": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-perplexity-ask"],
      "env": {
        "PERPLEXITY_API_KEY": "твой-ключ"
      }
    }
  }
}

Пример применения. Пишешь статью про конкурентов - говоришь Клоду «найди актуальные тарифы сервиса X» и он сам найдёт, без тебя.

2. Playwright MCP - Клод управляет браузером

Что даёт. Клод открывает Chrome, переходит по ссылкам, кликает на кнопки, заполняет формы, делает скриншоты. Это Microsoft-овский сервер на базе Playwright - стандартного инструмента для автоматизации браузера.

Использовать можно для автоматизации рутины на сайтах, тестирования интерфейсов, сбора данных с конкретных страниц, проверки как выглядит твой лендинг.

Установка. API-ключ не нужен.

bash
claude mcp add playwright -- npx @playwright/mcp@latest

Пример применения. «Зайди на мой сайт nextgenclub.ru, открой страницу тарифов и скажи что там написано». Клод открывает, читает, отвечает. Или: «пройди через форму регистрации и скажи где она ломается».

💡

Совет

Playwright при первом запуске скачает браузер Chromium (~150 МБ). Это нормально, произойдёт один раз.

3. Firecrawl MCP - краулинг и скрейпинг сайтов

Что даёт. Клод скачивает содержимое любого сайта в текст и работает с ним как с контекстом. Это не просто открыть страницу - это вытащить весь контент, включая сложные SPA-сайты, которые Playwright открывает медленнее.

Три основных режима:

  • scrape - вытащить одну страницу
  • crawl - пройтись по всему сайту
  • search - найти нужное внутри сайта

Хорошо работает для ресёрча конкурентов, сбора данных для RAG-систем, анализа чужого контента.

Установка. Нужен API-ключ Firecrawl. Бесплатный тир есть (500 страниц/месяц), для базового использования хватает.

Получить ключ: firecrawl.dev - зарегистрироваться и взять в настройках.

bash
claude mcp add firecrawl -- env FIRECRAWL_API_KEY=твой-ключ npx -y firecrawl-mcp

Репозиторий: firecrawl/firecrawl-mcp-server

Пример применения. «Скрейпни сайт конкурента competitor.ru и выпиши их тарифы и фичи». Клод пройдётся по сайту и вернёт структурированный текст, с которым дальше можно работать.

4. Glif MCP - генерация изображений и видео

Что даёт. Доступ к десяткам моделей генерации изображений и видео через платформу Glif. Клод сам выбирает подходящую модель под задачу и оптимизирует промпт - не надо самому разбираться в Midjourney, Flux, Stable Diffusion и других.

Подходит для генерации обложек, иллюстраций к статьям, прототипов визуала.

Установка. Нужен аккаунт на glif.app и API-токен. Есть бесплатный тир с лимитами на генерации.

Получить токен: в аккаунте Glif в разделе API.

bash
claude mcp add glif -- env GLIF_API_TOKEN=твой-токен npx -y @glifxyz/glif-mcp-server

Репозиторий: glifxyz/glif-mcp-server

Пример применения. Пишешь пост, говоришь Клоду «сгенери обложку для этой статьи в стиле минимализм, тема AI и продуктивность». Клод выберет модель, напишет промпт и вернёт картинку.

5. Chrome MCP - работа с тем, что уже открыто

Что даёт. Клод видит и взаимодействует с тем, что открыто у тебя в Chrome прямо сейчас. В отличие от Playwright, который открывает новый браузер отдельно, Chrome MCP работает с твоей текущей сессией: куки сохранены, ты уже залогинен на сайтах.

Полезно когда нужно работать с сайтами, куда нужна авторизация - личный кабинет, CRM, рабочие инструменты.

Установка. Нужно установить расширение для Chrome. Само расширение бесплатное.

Расширение: ищи «Claude for Chrome» или «Claude in Chrome» в Chrome Web Store.

bash
claude mcp add chrome-mcp -- npx -y @anthropic-ai/claude-in-chrome

Пример применения. Открываешь AmoCRM со своими лидами, говоришь Клоду «посмотри на открытую вкладку и выпиши все лиды в статусе "переговоры" в таблицу». Клод читает текущую страницу и выдаёт результат.

Главное

Итого что получаешь после установки всех пяти: - Поиск в интернете (Perplexity) - Управление новым браузером, автоматизация, тесты (Playwright) - Скрейпинг и краулинг сайтов (Firecrawl) - Генерация изображений (Glif) - Работа с твоим текущим Chrome (Chrome MCP)

Из пяти без ключей ставятся только Playwright и Chrome MCP. Остальные три требуют регистрации, но у всех есть бесплатные тиры.

Частые вопросы

Можно ли ставить MCP-серверы не в Claude Code, а в Claude Desktop?
Да, синтаксис почти одинаковый. В Desktop правишь claude_desktop_config.json, в Code - .claude/mcp.json или через claude mcp add.
Что если сервер не запускается?
Сначала проверь claude mcp list - видит ли Клод сервер вообще. Если видит, но не работает - скорее всего проблема с API-ключом или с Node.js. Запусти команду вручную в терминале и посмотри ошибку.
Платные ключи - это обязательно?
Для Perplexity, Firecrawl и Glif есть бесплатные тиры. Их хватает если пользуешься периодически, а не в промышленных масштабах. Playwright и Chrome MCP вообще без ключей.
