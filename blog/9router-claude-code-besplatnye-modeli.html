9Router: как подключить Claude Code к бесплатным моделям и не упираться в лимиты

Знакомая ситуация: работаешь в Claude Code, глубоко в задаче, и тут лимит подписки заканчивается. Сессия встаёт, а до следующего окна лимита ещё далеко. Или просто хочется попробовать Claude Code, но платить $20 в месяц раньше, чем понял, нужно оно тебе или нет, не хочется.

Нашёл рабочий инструмент под это - 9Router. Open-source, MIT-лицензия, больше 21 тысячи звёзд на GitHub. Показываю, как он работает и как подключить.

Что ты получишь из этой статьи

  • Рабочий способ не останавливать работу в Claude Code, когда кончился лимит
  • Пошаговую установку и подключение 9Router к Claude Code
  • Три реально бесплатных провайдера моделей, без карты и счёта
  • Честный разбор ограничений

Что делает 9Router

Это локальный прокси-роутер. Встаёт между Claude Code (и другими AI-инструментами для кода: Cursor, Codex, Cline, Copilot, Antigravity) и провайдерами моделей. Как только у тебя заканчивается лимит одного провайдера, 9Router автоматически переключает на следующий доступный, вплоть до полностью бесплатных моделей. Работа не останавливается.

Плюс у него есть RTK, компрессия запросов, которая уменьшает расход входных токенов на 20-40% на каждый запрос - экономия идёт ещё до того, как вопрос лимита вообще встанет.

Главное

Это не взлом и не обход Anthropic. 9Router использует официальный открытый протокол Claude Code и подключает к нему других провайдеров через их же официальные API. Всё легально, всё на открытом коде.

Что понадобится

  • Node.js (для сборки из исходников, для обычной установки не нужен)
  • npm
  • 5-10 минут

Установка

Проще всего через npm:

code
npm install -g 9router
9router

После этого открывается дашборд на http://localhost:20128. Там же показывается счётчик токенов и остаток лимита прямо в интерфейсе.

Есть ещё два способа, если этот не подходит:

Через Docker:

code
docker run -d --name 9router -p 20128:20128 -v "$HOME/.9router:/app/data" decolua/9router:latest

Из исходников (если хочешь ковыряться в коде):

code
cp .env.example .env
npm install
PORT=20128 NEXT_PUBLIC_BASE_URL=http://localhost:20128 npm run dev

Как подключить Claude Code

В конфиге ~/.claude/config.json прописываешь:

code
{
  "anthropic_api_base": "http://localhost:20128/v1",
  "anthropic_api_key": "твой-ключ-от-9router"
}

Ключ 9Router генерирует сам в дашборде, там же выбираешь конкретную модель или комбинацию моделей. После этого Claude Code думает, что общается с Anthropic напрямую, а на деле запросы идут через 9Router, и уже он решает, куда их направить.

Способ быстрее: отдай эту статью своему Claude

Это техническая инструкция, и Claude Code умеет выполнять её за тебя шаг за шагом.

Скопируй ссылку на эту страницу, открой Claude Code и напиши примерно так:

«Вот статья: https://nextgenclub.ru/blog/9router-claude-code-besplatnye-modeli. Прочитай её и настрой мне 9Router. Сделай всё по шагам из статьи, а в конце проверь, что конфиг подключён правильно.»

Он сходит по ссылке, разберёт инструкцию и пройдёт по всем шагам. Тебе останется только выбрать провайдера в дашборде и вставить ключ, если он нужен.

Какие провайдеры реально бесплатные

9Router поддерживает 40+ провайдеров (OpenAI, Gemini, DeepSeek, Groq, Mistral, Perplexity и другие), но бесплатны из них не все одинаково честно. Разработчик прямо выделяет три варианта без карты и без счёта:

OpenCode FreeБез авторизации$0, без лимита по объёмуПрокси-проход, модели подтягиваются автоматически
Vertex AIСервис-аккаунт Google Cloud$300 кредитов на 90 днейGemini и партнёрские модели

Совет

Начни с Kiro AI или OpenCode Free - там вообще не нужно вводить платёжные данные. Vertex AI хорош, если у тебя ещё не активирован Google Cloud и есть право на пробный период.

⚠️

Внимание

Разработчик 9Router отдельно предупреждает про Gemini CLI: подключать его через сторонние роутеры сейчас рискованно, есть шанс блокировки аккаунта, если инструмент не официальный Gemini CLI. Для Gemini безопаснее идти через Vertex AI.

Честно про ограничения

Дашборд 9Router показывает "стоимость" каждого запроса, но это условная оценка: сколько бы это стоило на платном API, а не реальный счёт. На бесплатных провайдерах с тебя не спишут ни рубля, цифра просто для ориентира.

Бесплатные модели решают повседневные задачи нормально, но настоящий Claude, особенно Opus и топовые версии Sonnet, на сложных многошаговых задачах всё ещё точнее. У бесплатных тиров тоже есть свои лимиты, просто более щедрые и раскиданные по разным провайдерам - поэтому 9Router и переключает между несколькими, а не полагается на один.

ℹ️

Заметка

Если гоняешь через OpenClaw, используй в адресе 127.0.0.1 вместо localhost - иначе возможны проблемы с резолвом IPv6.

Частые вопросы

Это легально?
Да. 9Router использует открытый протокол Claude Code и официальные API провайдеров. MIT-лицензия, открытый код на GitHub.
Нужна подписка Anthropic?
Нет, в этом и смысл. Можно подключить только бесплатных провайдеров и вообще не платить Anthropic, пока не понадобится что-то большее.
А если я всё же хочу платный Claude?
9Router прекрасно работает и как дополнение к платной подписке: пока лимит платного тарифа не кончился, запросы идут через него, а когда кончился, автоматически подключаются бесплатные модели вместо полной остановки работы.
Насколько это стабильно?
Проект активно растёт (десятки тысяч загрузок с npm, топ GitHub Trending на момент написания), но это молодой open-source проект, условия у отдельных провайдеров меняются. Раз в пару недель стоит проверять дашборд, не поменялось ли что-то у конкретного провайдера.
