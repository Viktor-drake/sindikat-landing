Установка: три команды

Открываешь Claude Code в любой папке и вводишь по очереди:

bash
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup

Третья команда нужна обязательно: она донастраивает окружение. После неё можно сразу просить аудит обычными словами, например «сделай полный SEO-аудит example.ru».

Заметка

В README есть вариант установки для участников закрытого сообщества автора. Он вам не нужен: публичная версия под MIT, без членства и без оплаты.

Что он реально проверяет

Аудит обходит сайт (до 500 страниц), определяет тип бизнеса и раскидывает работу по специалистам, которые считают параллельно. На выходе оценка от 0 до 100 и список задач по приоритету.

  1. Техническая часть. Индексация, robots, карта сайта, редиректы, дубли.
  2. Скорость. Что именно тормозит и насколько это бьёт по позициям.
  3. Разметка Schema.org. Чтобы Google и Яндекс понимали, кто вы и что продаёте.
  4. Содержание. Глубина текстов, сигналы экспертности, тонкие страницы.
  5. Видимость в нейросетях. Будут ли вас упоминать ChatGPT и AI-ответы поиска.

Главное

Пятый пункт сейчас недооценивают сильнее всего. Люди всё чаще спрашивают не поиск, а нейросеть. Если вас нет в её ответах, для этой части аудитории вас нет вообще, и никакие позиции в выдаче этого не компенсируют.

Главное отличие от платного отчёта

Обычный аудит заканчивается PDF-файлом, который надо кому-то отдать в работу.

Здесь отчёт и исполнитель это один и тот же диалог. Вы смотрите список проблем и говорите «чини вот это», и Claude Code начинает править сайт прямо в коде. Между «узнал о проблеме» и «проблема закрыта» не остаётся ни согласования, ни подрядчика, ни недели ожидания.

Чего ждать не стоит

Честно про границы, чтобы вы не разочаровались:

  • Он не заменит стратегию: не решит, по каким запросам вам вообще нужно расти.
  • Он не напишет за вас экспертность: тонкий текст станет технически исправным

тонким текстом.

  • Часть проверок требует доступов к Search Console и аналитике. Без них аудит

всё равно работает, но пара разделов будет беднее.

  • Сайт на закрытом конструкторе он починить не сможет, только показать, что не так.

Частые вопросы

Это правда бесплатно?
Да, плагин под MIT. Платите только за свою подписку Claude.
Нужно ли уметь программировать?
Для аудита нет, команды вводятся как есть. Для починки код будет писать Claude, но вам придётся подтверждать изменения.
Сколько занимает аудит?
Около десяти минут на средний сайт. Большие сайты дольше, обход ограничен 500 страницами.
А если у меня сайт на Тильде или Битриксе?
Проверить можно любой сайт. Автоматически починить получится там, где у вас есть доступ к коду или шаблонам.
Чем это отличается от бесплатных онлайн-чекеров?
Чекер показывает симптомы. Здесь после отчёта можно сразу сказать «исправь», и правки будут внесены.
