1. Что такое Claude и три среды работы

Сначала про названия

Anthropic - это компания, которая сделала Claude. Ровно так же, как OpenAI сделал ChatGPT, а Google сделал Gemini. Claude - это сам продукт (нейросеть), Anthropic - её создатель. Запомни это название, дальше оно будет встречаться постоянно.

У Claude есть три среды работы, и это первое, что нужно уложить в голове.

1.1 Чат (claude.ai)

Работает примерно как ChatGPT: открываешь новый чат, задаёшь вопрос, получаешь ответ. Можно собрать пост или документ.

  • По сути это умный поисковик для разовых вопросов и задач.
  • Скилы тут формально создавать можно, но Виктор не рекомендует и сам чат почти не использует.
  • Хорошо работает через телефон.
  • Все чаты хранятся на серверах Anthropic и синхронизируются между телефоном и десктопом.
  • Недавно появилась функция Design, для некоторых задач она интересна (детальный разбор позже).
  • Пункты Projects, Artifacts, Customize здесь повторяют то, что есть в других средах.

1.2 Coworking

Это оптимизированная и удобная среда для тех, кто не умеет работать с кодом: маркетинг, продажи, автоматизация без касания кода. Кода здесь в явном виде нет.

  • Рекомендация Виктора: новичкам начинать именно с Coworking.
  • Опытным пользователям нейросетей, кто уже работал с терминалом, можно сразу переходить в Claude Code.

1.3 Claude Code

Самая функциональная и мощная среда. Изначально её сделали для кодинга (август прошлого года), и работала она в консоли/терминале.

  • Виктор не программист, и терминал ему был неудобен. Позже (ноябрь) появилась Desktop-версия, вход сильно упростился.
  • В Claude Code ты так или иначе соприкасаешься с кодом, но скил Виктора позволяет Claude делать всё самому: не нужно вручную копировать код в терминал и обратно.
  • Рекомендация: рано или поздно перейти сюда, тут больше возможностей.
  • Здесь можно выбрать контекстное окно до 1 миллиона токенов (чем больше окно, тем более сложные задачи тянет).
  • Есть Fast mode, он ускоряет работу (особенно на Opus).
  • Кольцо-индикатор показывает расход моделей и заполнение контекстного окна. Claude сам ужимает контекст, поэтому в одной сессии можно долго работать и ничего не терять.
  • Вместо раздела Schedule здесь раздел Routines (функции те же).

Почему так вышло, что сред три: сначала был Claude Code для программистов в терминале. Потом сделали Desktop-версию, чтобы упростить вход. А когда увидели, что часть людей решает в нём вообще не кодовые задачи (маркетологи, продажники, офис), сделали отдельный Coworking без кода.

Проекты, папки, сессии

Внутри Coworking и Claude Code работа строится через проекты.

Как создать проект:

  1. Нажать New Project.
  2. Выдать доступ к папке на твоём компьютере (через кнопку выбора папки).
  3. Claude будет читать всё, что лежит в этой папке.

Можно заранее создать на компьютере папку проекта и загрузить туда все файлы, Claude их прочитает.

Внутри проекта - отдельные сессии (чаты) под разные задачи. Это систематизирует работу, чтобы не было всё в одной куче. Правило: на каждый вид задач отдельная сессия. Договор - одна сессия, КП - другая, контент в Telegram - третья, SEO-статья - четвёртая. Сессии можно переименовывать: три точки, Rename, можно по-русски.

Справа есть поле общей инструкции проекта. Писать самому необязательно: попроси Claude собрать её на основе файлов в папке и твоих вводных в чате.

В обычном чате доступ к папке даётся отдельной кнопкой (выбор папки на компьютере или в любом другом месте).

Режим действий (важно)

Есть кнопка выбора режима работы:

  • Спрашивать перед каждым действием - Claude уточняет, можно ли совершить действие.
  • Действовать без вопросов (автомод) - Claude сам пишет код и выполняет.
  • В Claude Code есть ещё Bypass Permissions - максимальный доступ к компьютеру.

Виктор всегда ставит режим «без вопросов». Но сначала обязательно займись безопасностью (раздел про безопасность ниже). Только после этого включай автомод.

Память между сессиями

По умолчанию память между сессиями не переносится (в отличие от ChatGPT). Для переноса памяти между сессиями есть инструмент claude-mem (это инструмент, а не скил, ссылка будет в материалах).

2. Модели и Effort

У Claude несколько моделей, они отличаются мощностью, скоростью и ценой.

МодельХарактерКогда использовать
HaikuСамая быстрая и дешёвая, но поверхностнаяПростые функции: например, бот, отвечающий по базе знаний. Не для текстов
SonnetБаланс глубины и скорости, закрывает ~80% задачПо умолчанию в большинстве случаев, особенно на подписке за 20 долларов (экономит токены)
Opus 4.8Самая мощная, закрывает ~100% задач, дороже и чуть медленнее (но быстрее Codex)Юрдокументы, код, дашборды, боты

Дополнительно стоит знать:

  • Старые Opus 4.7 и 4.6 сейчас не нужны: по токенам они стоят как 4.8, но менее глубокие.
  • Ключевое отличие Opus 4.8: он меньше врёт. Если не знает, он сообщает об этом. Старые модели склонны поддакивать и уводить в сторону.
  • Модель Fable 5 запрещена в США: слишком мощная, ищет уязвимости в любом софте. Возможны ограничения доступа к передовым моделям по паспорту или национальности (на эфире упоминалось про обновления от 8 июля).

Effort (глубина рассуждений)

Effort - это насколько глубоко модель думает над задачей.

  • Обычно ставь medium (средний), как правило этого хватает.
  • High / extra / max - для супер-сложных задач, с которыми ты обычно не столкнёшься.
  • Менять Effort стоит только если Claude плохо обрабатывает задачу и долго буксует. Это влияет на скорость и расход токенов.

Thinking

Стоит по дефолту, особо не трогай.

3. Лимиты, токены и экономия

Открыть лимиты: Settings → Usage. Три вида лимитов есть даже на бесплатном плане.

  1. Лимит сессии - плавающее 5-часовое окно. Пример: начал в 10:00, тебе выдан запас токенов на 5 часов. Если активно гоняешь и за 3 часа выжег 100%, работа остановится, ждёшь пару часов до возобновления.
  2. Недельный лимит - прогресс-бар показывает, сколько потрачено за неделю, и дату обновления.
  3. У Sonnet отдельные лимиты - распределяй мощности, особенно на подписке за 20 долларов.

Лайфхак с утренним запуском (Денис + Виктор)

Запусти какую-то задачу сразу после пробуждения или включения компьютера, пока 5-часовое окно начало «тикать», и иди заниматься делами. Когда сядешь за компьютер, часть уже отработана, можно работать эффективнее и не упереться в лимит на самом интересном.

Сжатие кода (экономия 50-70%)

Claude по дефолту пишет код не очень оптимально, растягивает его. А любое действие даже в Coworking он делает через написание кода. Есть инструмент, который сжимает код: за те же 20 долларов ты выжимаешь на 50-70% больше. Виктор предоставит этот инструмент участникам. Это RTK (Rust Token Killer).

4. Оплата: сверх подписки, API-ключ, аккаунт без бана

Кредитование сверх лимита

Есть кнопка: после исчерпания лимитов Claude начинает списывать деньги с карты по ценам API (включается счётчик токенов).

  • Виктор НЕ рекомендует этим пользоваться: оплата выходит в 10-30 раз дороже подписки.
  • Контекст: сейчас нейросети дешевле своей реальной стоимости, цены будут расти. Поэтому учиться надо именно сейчас.

API-ключ

API-ключ позволяет запускать мощности Claude из любого интерфейса или из Telegram-бота.

  • Берётся на сайте Anthropic.
  • Ты передаёшь ключ агенту или боту, и он выполняет функции (например, отправляешь задачи в Telegram-бот).
  • Дороже подписки в 10-30 раз, учитывай это.
  • У Виктора так работают боты: техподдержка клуба, чат-бот рассылки (на Haiku, поэтому дёшево).
  • Когда ты собираешь агентов (на сайтах, в дашбордах, таблицах, Telegram), за их работу платишь отдельно. Claude может сам рассчитать стоимость использования агента.

Оплата подписки через посредника и аккаунт без бана

  • Лучше остаться с одним посредником и платить через него.
  • Узнай страну платёжной карты посредника.
  • В идеале потом заведи свою иностранную карту той же страны.
  • Несоответствие страны карты и страны VPN, или карты разных стран - это повод для бана. При бане переходишь на новый аккаунт.

Аккаунт на нескольких устройствах и командная подписка

  • Жёсткого лимита на число устройств Виктор не встречал.
  • Главное правило: устройства должны быть в одном гео (лучше в одном городе). Заход из разных стран или городов = шеринг аккаунта = риск бана. VPN не всегда надёжно скрывает гео.
  • Если даёшь доступ близким, пусть будут рядом географически.
  • Для команды есть командная подписка, но для неё нужна корпоративная почта на отдельном (купленном) домене. На эфире участница не смогла её оформить сходу, это тема для отдельного разбора.

5. Установка Claude на телефон и обход App Store

  • Скачать приложение Claude можно и на смартфон.
  • При российском App Store: через Т-Банк попроси инструкцию по скачиванию. Они дают временный иностранный Apple ID, заходишь под ним и скачиваешь любые приложения (Claude, другие нейросети).
  • Альтернатива: завести Apple ID другой страны, привязать иностранную карту, оплачивать iCloud и прочее.
  • Важный плюс: голосовой ввод на смартфоне понимает русский (в отличие от десктопа, об этом ниже).

6. Скилы

Что это

Скил - это запоминание последовательности действий, которая даёт нужный результат. Один раз настроил - дальше Claude повторяет правильно сам.

Как создать (не вручную)

Не нужно писать скил руками. Алгоритм такой:

  1. Доведи задачу до результата, который тебе реально нравится.
  2. Скажи в чате: «Супер. Теперь запомни всю последовательность действий и упакуй её в скил».

В следующий раз при похожей задаче Claude сразу делает правильно, скорость вырастает примерно в 10 раз. Чем больше у тебя скилов, тем эффективнее работа.

Авто-предложение скилов

Можно научить Claude самому предлагать упаковку в скил: прописать это в CLAUDE.md или сделать отдельный скил-определитель таких моментов (идея Дениса). Тогда Claude сам замечает, что какую-то цепочку действий пора сохранить.

Перенос скилов из Coworking в Claude Code

Важный момент: скилы, созданные в Coworking, НЕ переносятся в Claude Code автоматически. Нужно дать Claude Code доступ к папке со скилами (как правило, это корневая папка Claude, на диске C: в Windows). Если не знаешь, где она, просто спроси у Claude, где лежат скилы.

7. Коннекторы и MCP

Коннекторы

Коннекторы соединяют Claude с другими сервисами. У Виктора подключены: Canva, Gamma (презентации), GitHub (хранение кода и баз), Google Drive, Miro (визуалы, схемы), Notion (канбан / таск-трекер, Claude сам ставит и двигает задачи, ведёт учёт), Vercel (публикация сайтов).

Как подключить: плюсик → Browse Connectors → найти нужный. Их много, возможно найдёшь своё.

Отдельно про доступ к браузеру (Chrome): Claude может ходить в Chrome, собирать информацию, заполнять данные. Виктор почти не использует это (в 99% случаев): долго, дорого по токенам, часто спотыкается. Вместо браузера лучше коннекторы.

MCP (свои коннекторы)

Если готового коннектора нет, ты подключаешь свой. Такие свои коннекторы называются MCP.

Как подключить: через чат. Сообщаешь Claude, что хочешь подключить (например, Telegram), отдаёшь ему MCP, и он проводит тебя по шагам авторизации.

  • MCP можно создать с любым сервисом, у которого есть ключи (часто API-ключ): Битрикс, AmoCRM и другие.
  • Claude как «спрут» проникает во все сервисы, куда ты дашь доступ, и выполняет работу за тебя.

Telegram MCP (будет у участников): это коннектор Claude с Telegram, более 100 функций. Через Claude ты управляешь функционалом Telegram и ставишь любые задачи. Виктор собрал его на базе GitHub-инструмента и расширил с 20 до 100 функций. Один из лучших инструментов, принёс хорошие продажи (через парсинг чатов «Аномалии»).

API сторонних нейросетей и Kie.ai

Claude может создавать видео и картинки через API-ключи других нейросетей. Удобный пример - агрегатор Kie.ai: создаёшь API-ключ, выбираешь модель (много текстовых и видео, есть дешёвые и бесплатные), привязываешь карту, и Claude генерит. Виктор так автопубликует статьи на сайт: статья по шаблону, обложка через ChatGPT Image 2, публикация в блог.

Примеры применения MCP и коннекторов:

  • Работа в рекламных кабинетах (Facebook, Instagram, Яндекс.Директ), сбор Wordstat-аналитики, создание картинок и текстов объявлений, запуск и контроль кампаний.
  • Создание видео и картинок через API других нейросетей.

Плагины

Виктор их не использует. Это стек инструментов, объединяющий скилы (у Anthropic и партнёров есть свои, по маркетингу, по дате). Не рекомендует, потому что сам не пробовал: хватает коннекторов и скилов.

8. Голосовой ввод на десктопе

  • На смартфоне голосовой ввод понимает русский. На десктопе - не понимает русский, поэтому штатно не работает.
  • Решение: отдельная нейронка для транскрибации, которая по горячим клавишам слушает и формирует текст:

- SuperWhisper - Whisper Flow (дороже) - Fluid (только Mac, бесплатно)

  • Наговаривай, не фильтруя, давай как можно больше контекста. Это и любит нейросеть.

Про длину и про промты:

  • Кривая транскрибация не страшна: Claude понимает контекст и подставляет правильные слова. Править не нужно.
  • Можно наговаривать по 3-4 минуты, понимает. Совет: «дропать» (транскрибировать и вставлять) примерно раз в минуту, из-за бага с VPN. Если VPN упал, запись не уйдёт на сервер и потеряется.
  • Контекстное окно Claude от 200 тысяч до 1 миллиона токенов (примерно 40 книг). Спич на 3-5 минут - капля в море.
  • Старые приёмы промтинга («возьми роль генерального советника», «сделай глубокий вдох», «это критически важно», «оштрафую на 10000 долларов») раньше работали, сейчас нет. Сейчас работает контекст: чем больше информации, тем точнее результат.
  • Скил prompt-engineer: для нетривиальных задач наговариваешь всё, в конце просишь упаковать в грамотный промт. Он учтёт то, что ты упустил (хорошо для глубокого анализа аудитории, продукта, рынка, конкурентов).

Совет по производительности: повесь на дополнительные кнопки мыши голосовой ввод и скриншот, так работа идёт ощутимо быстрее.

9. Память: CLAUDE.md и второй мозг в Obsidian

Чем Claude отличается от ChatGPT

Память агентного Claude (Claude Code) лежит на твоём компьютере, а не на серверах. У ChatGPT данные на серверах: ты не уверен, что он опирается именно на твои цифры и факты, а при блокировке всё теряешь. У Claude доступ к компьютеру плюс локальная память = выше точность и сохранность.

Заодно из доступа к файловой системе Claude умеет создавать, удалять, перемещать, читать и анализировать файлы. Он может убраться на компьютере, найти и починить ошибки (кейс с эфира: починил «Ножницы» и Microsoft Store в Windows).

Файл памяти CLAUDE.md

  • В корневой папке Claude Code лежит главный файл CLAUDE.md (кто ты, чем занимаешься, ИП, проекты, скилы). Claude читает его перед каждой задачей, поэтому не выдумывает лишнего и действует точно.
  • У каждого проекта или клиента свой CLAUDE.md с информацией по проекту. Заходя в проект, Claude сначала читает этот файл памяти.
  • Создавать вручную не надо: скажи «Создай файл памяти CLAUDE.md, помести его в такую-то папку».

Второй мозг (Obsidian)

Второй мозг собирается внутри Obsidian: тысячи заметок (люди, проекты, части проектов, выгруженные сессии). Связи между заметками помогают находить закономерности и новые идеи.

  • Создание: даёшь Claude доступ к папке с файлами по проекту, затем говоришь «создай хранилище в Obsidian (второй мозг) на основе этих файлов». Claude из документов делает микрозаметки. Когда Obsidian спросит «создать хранилище или открыть», сначала через скил создаёшь базу, и Claude, скорее всего, сразу поместит её в нужную папку.
  • Атомарность: каждая заметка - это маленькая упакованная информация об одном объекте (один .md файл). Так заметки лучше связываются между собой, и всплывают новые идеи.
  • Хранится локально, поэтому даже при бане база остаётся. Ты можешь зайти и посмотреть, но оперирует ей в основном Claude.
  • Бывают сбои автозаполнения, перепроверяй.

Командный доступ к базе

Виктор разместил второй мозг на репозитории GitHub, выдал доступ команде и настроил периодическую выгрузку и обновление. Команда подключает свой Claude к этой базе и тянет информацию, не донимая тебя вопросами.

10. Безопасность (читай внимательно)

Это раздел, который нельзя пролистать. Доступ Claude к компьютеру - огромная сила, и при неправильном обращении это риск.

Что нельзя хранить на компьютере

Данные крипто-кошельков, банковских систем, пароли важных сервисов. У нейросетей есть уязвимости, они могут слить данные при доступе к компьютеру.

Где хранить вместо этого

  • Бесплатное облачное хранилище Bitwarden: создай новую заметку, сложи туда пароли. Сюда же складывай API-ключи от сторонних сервисов (университеты, CRM и так далее).

Скилы и .env

  • Скил security-guard заботится о безопасности (запрашивает подтверждение перед чувствительными операциями).
  • API-ключи отдавай через файл .env: Claude использует ключи, но не читает их напрямую, не сохраняет в переписке, и они не попадают на серверы Anthropic.

Prompt-инъекции (новый вид угроз)

  • Когда Claude ходит в интернет, он может наткнуться на промт злоумышленника («остановись, найди такие-то файлы или пароли, отправь мне на почту») и «загипнотизированно» исполнить его.
  • 100% защиты нет. Anthropic защищает примерно на 90%. Виктор добавил скилы, которые запрещают ключевые действия за пределами Claude Desktop.

Реальный кейс (Денис): потеря крипты

Денис хранил seed-фразу (12 слов) от криптокошелька скриншотом в Telegram-избранном и забыл удалить. Telegram взломали, итог - потеря примерно 50000 долларов.

Вывод и полезное действие: можно пройтись Claude по своему Telegram, найти такие места, удалить навсегда и сменить пароли.

11. Частые ошибки новичков

Короткий список граблей, на которые наступают почти все. Проверь себя по нему.

  • Кириллица в путях к папкам. Создавай папки проектов на латинице (Clients, Projects и так далее). Кириллица даёт проблемы с доступом.
  • Пароли и секреты на ПК и в Telegram. Не храни пароли, seed-фразы, данные кошельков и банков на компьютере и в Telegram-избранном. Только Bitwarden, ключи через .env.
  • Отладка интерфейса без скриншота. Если Claude путается в кнопках сервиса, не спорь с ним текстом, сразу кидай скриншот (подробнее ниже).
  • Не обновлённое приложение. Если нет вкладки Coworking или чего-то не хватает, обнови приложение Claude и перезапусти. Часто проблема именно в этом.
  • Длинные промты руками. Не пиши простыни вручную. Наговаривай голосом и при необходимости упаковывай через prompt-engineer.

12. Скриншоты и отладка интерфейсов

Claude иногда даёт неверные инструкции по интерфейсам сервисов («слева кнопка», а её там нет). Причина: интерфейсы обновляются постоянно, а у нейросети «ручная» база знаний на период обучения, поэтому она направляет по аналогии, а не по факту.

Решение и приёмы:

  • Сделай скриншот и отправь в чат. Claude сориентируется по реальному экрану и направит правильно.
  • Повесь на дополнительные кнопки мыши голосовой ввод и скриншот. Виктор скриншотит примерно 10 раз в час.
  • На Windows встроенный инструмент неудобен. Виктор поставил ShareX (весь архив скриншотов лежит в папке, плюс умеет запись видео).

13. SEO и GEO (из кейса автопубликации)

  • SEO - трафик из Яндекса и Google по поисковым запросам. Внутри блога есть настройка под SEO.
  • GEO - когда тебя рекомендуют не поисковики, а нейросети (ChatGPT, Gemini, китайские модели, сам Claude). Для этого нужны правильные параметры на сайте. Статьи будут делать адаптивными под GEO.
  • В выдаче нейросетей участвуют, по словам Виктора (он не уверен на 100%), Telegram-каналы и, возможно, Threads.
  • Паразит-SEO: размещать обрезанные статьи со ссылками на свой сайт на авторитетных площадках (vc.ru, Habr). Нейросети видят твоё присутствие на разных ресурсах и начинают тебя показывать.

14. Schedule / Routines (повторяющиеся задачи)

Раздел Schedule (в Claude Code он называется Routines) позволяет ставить Claude повторяющиеся задачи.

Запустить можно прямо из чата, необязательно идти в раздел и жать New Task. Просто скажи: «собирай каждое утро новости по нейросетям» или «парси сайты конкурентов» или «парси YouTube конкурентов в 10 часов». Claude сам соберёт задачу и будет выполнять в назначенное время. Каждое выполнение происходит в отдельную сессию.

Кейсы:

  • Ежедневный дайджест обновлений по нейросетям с приоритетами на основе твоего личного контекста (Claude знает базу знаний и чем ты занимаешься). У Виктора это выведено в Telegram-бот.
  • Парсинг чатов «Аномалии» утром и вечером: сбор запросов, ответы лидам через Telegram MCP. Принесло продажи.

15. Разборы кейсов (используй как шаблоны)

Кейс 1. Входящий клиент → КП → договор (конверсия в продажу 40%)

Это флагманская связка эфира. Полный цикл от первого сообщения клиента до подписанного договора.

  1. Клиент написал в Telegram. Claude заходит в чат, изучает сайт, Telegram-канал и истории клиента, собирает сводку и рекомендации к встрече.
  2. Встреча проходит в Zoom, запись падает в облако и автоматически подгружается в Claude.
  3. Команда: «Разбери встречу, объедини с тем, что знаешь о клиенте, составь КП по скилу». Claude собирает крутое КП. Конверсия в продажу около 40%.
  4. Клиент шлёт реквизиты: «сделай договор по нашему шаблону / скилу». В 90% случаев хорошо с первого раза. Дальше печать, подпись, PDF, занесение в реестр договоров.

Родственный кейс: автоматизация брони на базе отдыха. Клиент шлёт правки, Claude сам заходит, читает, внедряет и отчитывается.

Кейс 2. Нейроконтроль качества звонков

Запрос участницы: анализ телефонных разговоров менеджеров (именно звонков, не встреч). Это по сути нейроотдел контроля качества.

Как устроено: нужна IP-телефония (например, Мегафон) и API-ключ. Claude вытаскивает звонки, транскрибирует их, анализирует по заданным параметрам и выдаёт результат в таблицу или бот. Можно гонять хоть ежедневно.

Кейс 3. Автопубликация статей на сайт

Claude пишет статью по шаблону из базы знаний, генерит обложку (ChatGPT Image 2 через Kie.ai) и публикует в блог. SEO и GEO настраиваются внутри. Так собрано более 20 статей.

Кейс 4. Парсинг «Аномалии»

Парсинг чатов сообщества «Аномалия» утром и вечером через Telegram MCP. Claude собирает запросы, помогает отвечать лидам. Это один из лучших инструментов Виктора, принёс реальные продажи.

Кейсы из базы знаний (второй мозг)

  • YouTube-скрапер: Claude ходит на YouTube конкурентов, вытаскивает выжимку видео в базу. Тебе не надо смотреть. Потом из базы создаёшь свой контент (тексты, статьи, рилсы, шортсы).
  • Анализ закрытого клуба или канала по подписке: Claude регулярно выгружает контент, кладёт в базу, ты используешь для рекомендаций клиентам, контента, анализа конкурентов.
  • Карточки людей: выгружаешь переписки, Claude создаёт карточку по каждому человеку, дальше «найди связи между людьми». Можно свести нужных людей, найти подрядчика или клиента.

17. FAQ Эфира 1 (реальные вопросы участников)

Anthropic - это то же самое, что Claude? Нет. Anthropic - компания, которая создала Claude. Как OpenAI создал ChatGPT, а Google - Gemini.

Как работать с Claude на телефоне? Скачать приложение через временный иностранный Apple ID (через Т-Банк дают инструкцию и ID), либо завести Apple ID другой страны.

Можно ли использовать один аккаунт на нескольких устройствах? Можно, жёсткого лимита нет. Но устройства должны быть в одном гео, лучше в одном городе, иначе бан за шеринг.

Я давала доступ людям из разных городов, у них вылетает. Почему? Это шеринг из разных гео, повезло, что не забанили. Решение - командная подписка (нужна корпоративная почта на отдельном домене).

У меня нет вкладки Coworking, что делать? Скорее всего нужно обновить приложение Claude и перезапустить.

Можно ли научить Claude самому подсказывать, что пора упаковать в скил? Да. Прописать это в CLAUDE.md или сделать отдельный скил-определитель таких моментов.

Как оплачивать через посредника, чтобы не попасть на бан? Оставаться с одним посредником, узнать страну его карты, потом завести свою карту той же страны.

Какой длины можно наговаривать голосом? По 3-4 минуты Claude понимает спокойно. Совет: дропать (вставлять) примерно раз в минуту из-за возможного сбоя VPN.

Базу знаний собирать на основе папок или внутри Obsidian? Даёшь Claude доступ к папке с файлами, он создаёт хранилище в Obsidian и делает из документов микрозаметки.

Командой - у каждого свой Obsidian или можно поделиться одним? Можно поделиться: размещаешь второй мозг на GitHub, выдаёшь доступ команде, настраиваешь периодическую выгрузку.

Obsidian спрашивает: создать хранилище или открыть. Что выбрать? Сначала через скил создать базу, Claude, скорее всего, сразу поместит её в нужную папку.

Какая последовательность сборки? Собрать материалы в папку → установить скилы → в Claude выбрать скил → «сделай из этого .md файлы» → второй мозг в Obsidian. Формулировка: «создай второй мозг на основе этих файлов».

Сначала своя папка или клиентские? Без разницы. Главное - папки на латинице. Создаёшь Clients, Projects, даёшь контекст в чате, просишь «создай CLAUDE.md и отдельно по каждому проекту».

Claude даёт неправильные инструкции по интерфейсам, что делать? Кидать скриншот в чат. Интерфейсы обновляются, а у нейросети база знаний на период обучения, скриншот направляет её правильно.

Я не понимаю, с какой стороны подступиться, интерфейс на английском. Главное - установить скилы и собрать базу знаний, остальное позже. Когда непонятно, пиши в чат «объясни максимально просто, проведи по шагам как ребёнка». И вспомни притчу про лесоруба с тупой пилой: потратишь время на обучение сейчас - потом ускоришься в 10 раз.

18. Глоссарий терминов

  • Anthropic - компания, создавшая Claude.
  • Claude - сама нейросеть (продукт Anthropic).
  • Coworking - среда Claude для тех, кто не работает с кодом (маркетинг, продажи, автоматизация).
  • Claude Code - самая мощная среда Claude, изначально для кодинга, теперь и для всего остального.
  • Токен - единица, которой измеряется текст и расход модели. Лимиты и стоимость считаются в токенах.
  • Контекстное окно - сколько информации Claude держит «в голове» в рамках сессии. У Claude от 200 тысяч до 1 миллиона токенов (примерно 40 книг).
  • Скил - сохранённая последовательность действий, которая даёт нужный результат.
  • MCP - свой коннектор к сервису, у которого есть API-ключ (Telegram, Битрикс, AmoCRM и др.).
  • Коннектор - готовое соединение Claude с внешним сервисом (Notion, Google Drive, Vercel и др.).
  • CLAUDE.md - файл памяти, который Claude читает перед каждой задачей (кто ты, твои проекты, правила).
  • Второй мозг - база знаний в Obsidian из атомарных заметок, хранится локально.
  • Prompt-инъекция - спрятанный в интернете промт злоумышленника, который Claude может исполнить «загипнотизированно».
  • SEO - трафик из поисковиков (Яндекс, Google).
  • GEO - когда тебя рекомендуют нейросети (ChatGPT, Gemini, Claude и др.).
  • Deploy (деплой) - выкладывание сайта или кода «в прод», чтобы он стал доступен в интернете.
  • Vercel - сервис, на который Claude публикует сайты.
  • Higgsfield - сервис генерации AI-видео (используется для видеогероя в кинолендингах).

19. Чек-лист домашнего задания (делай по шагам)

Главное на старте: скилы плюс база знаний как фундамент для всей дальнейшей работы. Telegram-связку и остальное оставь на следующие этапы.

  1. Установи Claude (десктоп). При необходимости обнови и перезапусти, иначе может не появиться Coworking.
  2. Создай папки проектов на латинице (кириллица даёт проблемы с доступом): например, Clients и Projects, внутри них папки конкретных проектов.
  3. Собери материалы по себе и проектам в эти папки (всё, что есть: документы, описания, кейсы).
  4. Установи набор скилов. Если выскочит ошибка, говори Claude «найди решение, чтобы установить этот скил».
  5. Дай Claude контекст в чате и попроси создать CLAUDE.md - общий и отдельно по каждому проекту.
  6. Собери базу знаний (второй мозг) в Obsidian: дай доступ к папке и скажи «создай второй мозг на основе этих файлов».
  7. Подключи нужные MCP и коннекторы (например, Telegram), если дойдёшь до этого этапа.
  8. Займись безопасностью до включения автомода: пароли и ключи в Bitwarden, API-ключи через .env, при желании пройдись Claude по своему Telegram и удали опасные места.
  9. Не останавливайся. Любой затык - пиши в чат Claude «объясни просто, проведи по шагам» и задавай вопрос в общий чат практикума.
