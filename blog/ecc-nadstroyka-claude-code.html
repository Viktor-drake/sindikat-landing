ECC это надстройка над Claude Code: набор агентов, скиллов, команд и хуков, который превращает чат с моделью в конвейер. Репозиторий бесплатный, лицензия MIT.

Что меняется в работе

Обычный Claude Code это диалог: ты просишь, он делает. ECC навязывает порядок: сначала план, потом тесты, потом код, потом ревью, и только потом коммит.

Четыре слоя, из которых он собран:

  1. Агенты под конкретные роли: планирование, ревью, безопасность, отдельные языки.
  2. Скиллы и команды, то есть готовые сценарии вместо каждый раз нового промпта.
  3. Память вне контекста, из-за чего длинные сессии не разваливаются на середине.
  4. Хуки: форматирование после правок, блокировка опасных команд, проверка на утечку ключей.

Четвёртый пункт недооценивают. Хук, который не даёт закоммитить файл с ключом, окупает установку целиком в тот единственный раз, когда он сработает.

Цена, о которой не пишут

Теперь то, чего нет ни в одном обзоре, и ради чего стоило ставить это в песочницу.

Claude Code читает описания всех установленных агентов и скиллов, чтобы понимать, что у него под рукой. Эти описания попадают в контекст каждой сессии, ещё до того, как ты напишешь первое слово.

Я посчитал их в своей копии: 193 описания, 47 769 символов. По грубой оценке это примерно 12-16 тысяч токенов постоянной нагрузки на сессию.

Главное

ECC не бесплатен по контексту. Полная установка забирает порядка 12-16 тысяч токенов в каждой сессии просто за факт своего присутствия. Это не повод отказываться, это повод ставить нужную часть, а не всё подряд.

Ровно та же история была у Agency Agents, я разбирал её в статье про 279 субагентов для Claude Code. Закономерность общая: чем больше готовый набор, тем дороже он обходится до начала работы. Полезно об этом помнить, когда в ленте показывают очередной репозиторий на тысячу агентов.

Как поставить и не сломать рабочую систему

Главное правило: сначала в отдельную папку, потом в бой. Любой репозиторий, который раскладывает шесть сотен файлов в твой .claude, надо сперва посмотреть в изоляции. Я так и сделал, и именно поэтому могу приводить цифры выше.

Порядок:

bash
# 1. Пустая песочница, не рабочий проект
mkdir ecc-test && cd ecc-test

# 2. Установка
npx ecc-universal@2.2.1 setup

# 3. Посмотреть, что реально приехало
ls .claude/agents | wc -l
ls .claude/skills | wc -l
ls .claude/commands | wc -l

Дальше открываешь Claude Code в этой папке, гоняешь свою типовую задачу и смотришь, стало ли лучше. Если да, ставишь в рабочий проект. Если нет, удаляешь папку и ничего не потерял.

⚠️

Внимание

Не запускай установку сразу в своём основном проекте. Откатывать 620 файлов вручную, если тебе не подойдёт, это отдельный неприятный вечер.

Частые вопросы

ECC платный?
Нет. Репозиторий под лицензией MIT, пакет в npm открытый. Платишь только за свою подписку Claude.
Он заменяет Claude Code?
Нет, это надстройка. Claude Code остаётся, ECC добавляет ему агентов, скиллы, команды и хуки.
Можно поставить только часть?
Да, и это правильный путь. Профиль выбирается при установке, а лишние агенты и скиллы из .claude можно удалить: каждый из них это отдельная папка с файлом описания.
Почему важна цена контекста?
Потому что съеденные описаниями токены это токены, которых не хватит на твой код в длинной сессии. Чем компактнее набор, тем дольше живёт сессия.
Стоит ли ставить, если я не программист?
Скорее нет. ECC заточен под разработку с тестами и ревью. Если ты используешь Claude Code для текстов и автоматизации, выигрыша будет мало, а контекст он съест так же.
