Инстаграм-аналитика в чате с Claude: как подключить через официальный Meta API

Виктор Дачников 4 июля 2026 7 минут

🟡 Средний уровень - понадобится аккаунт Meta for Developers, программирование не обязательно

Что ты получишь, прочитав эту статью

  • Поймёшь, откуда Instagram Business/Creator берёт цифры аналитики и как достать их напрямую
  • Настроишь приложение в Meta for Developers и получишь свой токен доступа - для своего аккаунта это делается без ревью Meta
  • Узнаешь точный запрос к API, который отдаёт охваты, показы, сохранения и демографию
  • Научишься отдавать эти данные Claude и спрашивать в чате вместо ручного сбора цифр

Статистику своего аккаунта обычно смотрят руками: открыл вкладку, выписал цифры, сравнил с прошлым месяцем в блокноте. Instagram Business и Creator-аккаунты отдают те же данные через официальный Graph API - если один раз настроить доступ, дальше можно просто спрашивать Claude: «сравни охваты за май и июнь, что выросло» и получать разбор на реальных данных.

Что для этого нужно

  • Instagram-аккаунт типа Professional - Business или Creator. Личный аккаунт для этого закрыт, это ограничение самой Meta, не техническое.
  • Аккаунт разработчика на Meta for Developers (developers.facebook.com) - бесплатно, обычный вход через Facebook.
  • Токен доступа с разрешением на чтение аналитики своего аккаунта.

Важный момент, который часто пугает раньше времени: если аналитика нужна тебе для своего же аккаунта, никакое ревью Meta проходить не нужно. Полная процедура с Business Verification и App Review нужна, только если делаешь сервис, который должен работать с чужими аккаунтами (агентство, продукт для клиентов). Для личного дашборда - следующих шагов достаточно.

Шаг 1. Создать приложение в Meta for Developers

  1. Зайди на developers.facebook.com под своим Facebook-аккаунтом.
  2. My Apps → Create App. Тип приложения - Business.
  3. В настройках приложения найди раздел продуктов и добавь Instagram API with Instagram Login.
  4. В App Dashboard заполни базовые поля - иконку, категорию, контактный email. Для личного использования (без подачи на ревью) строгих требований к этим полям нет, но система может попросить их заполнить, чтобы включить OAuth.

Шаг 2. Подключить свой Instagram-аккаунт

  1. В разделе Instagram → API setup with Instagram login укажи Redirect URI - куда Meta вернёт токен после входа.
  2. Пройди авторизацию под своим Instagram Professional-аккаунтом, подтверди запрошенные разрешения.
  3. Так как это твой собственный аккаунт с ролью в этом же приложении - доступ выдаётся сразу, на уровне Standard Access, без ожидания и ревью.

Разрешения, которые нужны: базовое instagram_business_basic (идентификация аккаунта) и разрешение на чтение аналитики - в официальной документации Meta оно называется по тому же паттерну, что и остальные права этого продукта (instagram_business_manage_*); точное название стоит свериться в актуальном разделе Permissions документации Meta на момент настройки, там периодически меняются формулировки.

Шаг 3. Получить долгоживущий токен

Короткий токен после авторизации живёт недолго. Его нужно обменять на долгоживущий - такой действует около 60 дней и его можно продлевать запросом до истечения срока. Шаг делается один раз при настройке, дальше только периодически продлевать.

Сохрани токен и ID своего Instagram-аккаунта - они понадобятся для каждого запроса. Как и с любым токеном - не публикуй его в коде и не отправляй в чаты, храни в переменных окружения.

Шаг 4. Запросить аналитику

Данные приходят через endpoint /insights на аккаунт целиком или на конкретную публикацию:

code
GET https://graph.instagram.com/v21.0/{ig-user-id}/insights
    ?metric=reach,impressions,saved,profile_views
    &period=day
    &access_token={токен}

В ответе - JSON с цифрами за выбранный период. Для аналитики по конкретному посту или рилсу такой же запрос делается на /{media-id}/insights с набором метрик, актуальным для этого типа публикации.

Шаг 5. Отдать данные Claude

Дальше это уже просто данные, с которыми Claude умеет работать:

  • Самый простой вариант. Сделай короткий скрипт (или попроси Claude Code написать его самому по шагам 1-4 выше), который делает запрос к /insights и сохраняет результат в файл. Дальше в любом чате с Claude отдаёшь этот файл и спрашиваешь: «сравни охваты за май и июнь, что выросло, какие посты дали больше сохранений».
  • Вариант с автоматизацией. Если хочешь спрашивать прямо в диалоге без ручного шага «сначала выгрузить файл» - заворачиваешь тот же запрос к /insights в MCP-сервер (небольшая обёртка, которая по команде Claude сама дёргает Graph API и возвращает данные). Тогда достаточно спросить в чате, а Claude сам подтянет актуальные цифры.

В обоих случаях подготовительная работа - настройка токена по шагам 1-3. Дальше это переиспользуется без повторной настройки.

Частые вопросы

Обязательно ли проходить Business Verification и App Review?
Нет, если аналитика нужна для твоего собственного аккаунта. Это требуется только когда приложение должно работать с аккаунтами других людей - например, если строишь сервис для клиентов.
Чем Business отличается от Creator-аккаунта в этом контексте?
Для доступа к Graph API подходят оба типа - главное, чтобы аккаунт был переключён в Professional-режим, а не оставался личным.
Сколько это стоит?
Само подключение и запросы к Graph API бесплатны. Платишь только за токены Claude, если используешь автоматизацию через MCP или скрипт.
Токен истечёт - что тогда?
Долгоживущий токен нужно продлевать до истечения срока действия отдельным запросом к API. Если пропустить момент - придётся заново проходить авторизацию по шагу 2.
Можно ли так же вытащить аналитику по конкретному рилсу, а не по всему аккаунту?
Да, тот же принцип - запрос на /{media-id}/insights вместо /{ig-user-id}/insights, с набором метрик под тип публикации (рилс, карусель, фото).
