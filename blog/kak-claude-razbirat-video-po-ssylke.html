Как Claude разбирает видео по ссылке: моя сборка для контент-ресёрча

Виктор Дачников 17 июня 2026 6 минут

🔴 Продвинутый — для тех, кто уже работает с Claude Code и знаком с понятием скиллов

⚡ Не обязательно читать всю статью Скопируй ссылку на эту статью и отдай Клоду: «Прочитай статью и настрой мне reels-viewer + youtube-analyzer». Он прочитает её сам и проведёт по установке, отвечая на твои вопросы по ходу. Если хочешь разобраться сам — читай дальше.

  • Поймёшь, зачем разбирать чужой контент через Claude, а не «просмотром».
  • Узнаешь, что нужно для запуска: Claude Code, скиллы, ffmpeg, yt-dlp.
  • Увидишь, что приходит в ответе: транскрипт, хук, структура, оценка.
  • Научишься скидывать пачку ссылок и получать сводные паттерны по всей подборке.

Смотреть чужие ролики полезно. Но «смотреть и чувствовать» это не анализ, это впечатление. После 10 видео ты уже не помнишь, в каком именно ролике был тот удачный хук, почему один набрал 200 тысяч просмотров, а похожий с той же темой завис на 3 тысячах. Данные уходят, паттерны не складываются.

Я решил эту задачу иначе: даю Claude ссылку и получаю структурированный разбор. Расскажу как это работает и что для этого нужно.

Главное

В Claude Code есть два скилла для разбора видео: reels-viewer для рилсов и TikTok, youtube-analyzer для YouTube. Они дают транскрипт, анализ хука и структуры, объяснение почему ролик зашёл. Можно скинуть пачку ссылок и получить сводные паттерны. Это рабочий ресёрч-инструмент, а не кнопка-магия: нужен Claude Code + ffmpeg + yt-dlp, часть приватных или гео-закрытых видео не качается.

Зачем анализировать по ссылке, а не просто смотреть

Когда смотришь ролик глазами, замечаешь общее: красиво снято, бодрая музыка, харизматичный автор. Но содержательный анализ требует другого: зафиксировать дословный текст первых 5 секунд, разметить структуру по тайм-кодам, сравнить это с тем, как сделаны 15 других роликов в нише.

Руками это занимает полдня. Клод делает это за минуту, причём по каждому ролику в одном формате, который потом можно сравнивать.

Конкретный пример: я разбираю конкурентов в EdTech-нише перед записью своих рилсов. Скидываю 10-15 ссылок на ролики, которые хорошо зашли, получаю по каждому транскрипт и разбор структуры, а потом сводный отчёт: какие хуки повторяются, какова средняя длина, есть ли общий паттерн в финальных призывах. Это уже материал для работы, а не ощущение после просмотра.

Что нужно для запуска

Это не плагин и не сайт с полем для ссылки. Это скиллы, которые работают внутри Claude Code на твоей машине.

Необходимое:

  • Claude Code (установленный и настроенный)
  • Скилл reels-viewer для рилсов Instagram и TikTok
  • Скилл youtube-analyzer для YouTube
  • ffmpeg — извлекает кадры и аудио из видео
  • yt-dlp — скачивает видео по ссылке
  • Node.js (обычно уже стоит если Claude Code настроен)

Честно про ограничения: часть видео не скачивается. Приватные аккаунты, закрытые группы, ролики с гео-блоком для РФ, некоторые видео TikTok. Это ограничение самого yt-dlp, не скилла. Публичный контент, который доступен в браузере без авторизации, качается нормально.

Как разобрать одно видео

Берёшь ссылку и отдаёшь Клоду с одним из двух скиллов:

Для рилса или TikTok:

code
/reels-viewer https://www.instagram.com/reel/...

Для YouTube:

code
/youtube-analyzer https://www.youtube.com/watch?v=...

Что происходит под капотом у reels-viewer: yt-dlp скачивает видео, ffmpeg вытаскивает кадры и аудио, faster-whisper транскрибирует речь, кадры читаются визуально. В итоге Клод видит ролик изнутри: дословный текст + что происходит на экране.

Что происходит у youtube-analyzer: yt-dlp тянет субтитры или транскрипт прямо из YouTube. Если они есть, отдаёт почти мгновенно. Если нет, транскрибирует аудио.

Что получаешь в ответе:

  • Транскрипт — дословный текст ролика с разбивкой по времени
  • Хук — первые 3-5 секунд, дословно и с оценкой: почему должно цеплять
  • Структура — как устроен ролик по блокам (открытие, тело, CTA или его отсутствие)
  • Визуальная подача — что происходит в кадре, монтаж, темп
  • Почему зашло или почему нет — оценка с обоснованием

Это не гадание на кофейной гуще, а разбор по факту: что реально сказано и показано, как это соотносится с тем, что работает в нише.

💡

Совет

Если делаешь регулярный ресёрч в одной нише, создай себе шаблон запроса: «разбери ролик, обращая внимание на X, Y, Z». Клод будет применять один фокус ко всем видео в серии, и потом это удобно сравнивать.

Batch-анализ: пачка ссылок за один раз

Разбор одного ролика полезен. Разбор 10-15 за один запрос даёт кое-что ценнее: паттерны.

Можно скинуть пачку ссылок одним запросом:

code
Разбери эти ролики по одному и потом дай сводный отчёт:
https://www.youtube.com/watch?v=...
https://www.youtube.com/watch?v=...
https://www.instagram.com/reel/...
[ещё ссылки]

Клод разберёт каждый по отдельности, а потом синтезирует по всей подборке:

  • какие типы хуков встречаются чаще всего
  • средняя длина и структура роликов, которые набирают просмотры
  • какие темы и углы повторяются
  • что делают авторы в конце: призыв к действию, вопрос, клиффхэнгер

Это конкретно помогает перед планированием серии контента: видишь что работает у других, понимаешь куда заходить, а куда уже переполнено.

ℹ️

Заметка

Batch-режим работает последовательно, не параллельно. Если скидываешь 20 ссылок, будь готов что это займёт несколько минут, особенно с рилсами (там скачивание + транскрипция). Для первого раза возьми 5-7 роликов.

Как настроить: пошаговые шаги

Это технический инструмент, его нужно настроить один раз. Дальше работает через простые команды.

Шаг 1. Убедись, что Claude Code установлен и запускается. Если нет — сначала туда. Статья Claude Code без программирования и бесплатный доступ к Claude Code помогут.

Шаг 2. Установи ffmpeg и yt-dlp. На Windows это делается через winget или chocolatey, на Mac через homebrew:

bash
# Mac
brew install ffmpeg yt-dlp

# Windows (через winget)
winget install ffmpeg
winget install yt-dlp

Шаг 3. Скилл reels-viewer и youtube-analyzer должны быть подключены к твоей сборке Claude Code. Если не знаешь что это такое и как подключить скиллы, открой Claude Code и напиши: «Прочитай эту статью и настрой мне reels-viewer + youtube-analyzer» — он сам пройдёт по шагам.

Шаг 4. Проверь работу на публичном YouTube-ролике (самый простой случай, обычно работает сразу).

Частые вопросы

Работает ли это с закрытыми или приватными аккаунтами?
Нет. yt-dlp качает только то, что доступно публично без авторизации. Приватные аккаунты Instagram, закрытые TikTok-аккаунты и гео-блокированный контент не скачаются.
Насколько точная транскрипция?
Для русскоязычного контента faster-whisper даёт хорошее качество, но иногда путается с именами, жаргоном и быстрой речью. Проверяй транскрипт, не принимай слепо за истину.
Можно ли разбирать видео конкурентов систематически?
Да, это основной сценарий. Составь список каналов и аккаунтов, регулярно скидывай свежие ролики на разбор. Клод запомнит твой формат запроса если работать в одной сессии.
Нужно ли платить за каждый разбор?
Расходуются токены Claude. Один разбор ролика стоит дёшево, batch из 10-15 чуть дороже. При подписке Max это в пределах лимитов, при pay-as-you-go считается по стандартным ценам Anthropic.
reels-viewer работает только с Instagram?
Нет, он работает со всем, что умеет качать yt-dlp: Instagram, TikTok, часть других платформ. YouTube лучше через youtube-analyzer — там субтитры подтягиваются напрямую без полного скачивания.
