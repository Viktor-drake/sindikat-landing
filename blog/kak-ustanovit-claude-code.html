Как установить Claude Code на Windows, Mac и из России: пошагово 2026

Виктор Дачников 22 июля 2026 8 минут

Claude Code ставится одной командой в терминале, а не скачивается как обычная программа с сайта. На Windows это одна строка в PowerShell, на Mac одна в терминале. Есть и графическое приложение для тех, кто с терминалом не дружит. Ниже разберём все способы по порядку, что нужно до установки и как проверить, что всё заработало.

Сразу важное: Claude Code требует платного плана Anthropic, на бесплатном его нет. А из России ещё нужен доступ к сервису. Про это в конце, с ссылками.

Почему Claude Code не «скачивают»

Многие ищут «скачать Claude Code», ожидая найти установщик-exe, как у обычной программы. Так это не работает, и это нормально.

Claude Code это инструмент командной строки (CLI). Ты ставишь его одной командой, а система сама скачивает и распаковывает нужный файл. Обновляется он тоже сам, в фоне, докачивать ничего не надо.

Если терминал пугает, есть второй путь: графическое приложение Claude Desktop, где Claude Code работает в окне, без командной строки. Про него отдельно ниже.

И сразу закроем частый вопрос: нативного приложения Claude Code для Android или iOS нет. Это инструмент для компьютера (Windows, Mac, Linux). На телефоне с ним работают только окольными путями через удалённый сервер, для старта это не нужно.

Установка на Windows

Windows это самая частая платформа, поэтому начнём с неё. Ставится в две минуты.

Способ 1, через PowerShell. Открой PowerShell (нажми Пуск, набери «PowerShell», запусти) и вставь одну команду:

powershell
irm https://claude.ai/install.ps1 | iex

Готово. Команда сама скачает и установит Claude Code. Права администратора не нужны.

Способ 2, через WinGet. Если у тебя есть менеджер пакетов WinGet (в свежих Windows он встроен), можно так:

powershell
winget install Anthropic.ClaudeCode

Один совет по Windows. Поставь Git for Windows, если его ещё нет. Он не обязателен, но с ним Claude Code получает доступ к Bash и работает полнее. Без него он использует PowerShell, тоже рабочий вариант, просто чуть уже возможности.

Установка на Mac

На macOS два удобных способа.

Через терминал (открой приложение «Терминал» и вставь):

bash
curl -fsSL https://claude.ai/install.sh | bash

Через Homebrew, если он у тебя стоит:

bash
brew install --cask claude-code

Разница в мелочи: нативная установка через curl обновляется сама в фоне, а Homebrew-версию надо обновлять руками командой brew upgrade claude-code.

Установка на Linux

Та же команда, что на Mac через терминал:

bash
curl -fsSL https://claude.ai/install.sh | bash

Для Debian, Ubuntu, Fedora и Alpine есть ещё установка через системный пакетный менеджер (apt, dnf, apk) из подписанного репозитория Anthropic, но для большинства достаточно команды выше.

Вариант без терминала: приложение Claude Desktop

Если командная строка не твоё, скачай графическое приложение. Это полноценное окно, где Claude Code работает мышкой и кликами, а не командами. Есть версии под Windows, Mac и Linux, скачиваются с официального сайта Anthropic как обычная программа.

Для новичка это часто более комфортный старт: ставишь как любое приложение, запускаешь, работаешь. А к терминалу можно перейти позже, когда освоишься.

Что нужно до установки

Два условия, без которых Claude Code не запустится.

1. Платный план Anthropic. На бесплатном плане Claude Code недоступен, нужен минимум Pro за $20 в месяц (или Max, или корпоративный). Это не наша прихоть, а требование Anthropic.

2. Доступ из России. Сайт Anthropic заблокирован в РФ, и оплата российской картой напрямую не проходит. И то, и другое решается легально: как получить доступ, зарегистрироваться и оплатить рублями, разобрано в статье «Claude в России: как получить доступ и начать пользоваться».

Отдельно: если хочешь попробовать Claude Code бесплатно, есть обходной путь через open-source коннектор на бесплатных моделях. Это не полноценный Claude, но для знакомства годится, подробности в статье про бесплатный Claude Code.

Проверка установки

После установки открой терминал (или PowerShell) и набери:

bash
claude --version

Если всё встало, увидишь номер версии, что-то вроде 2.1.211 (Claude Code). Появилась версия, значит установка прошла.

Для более полной диагностики есть команда:

bash
claude doctor

Она проверяет установку и настройки и подсказывает, если что-то не так. Полезно, если первый запуск ругается.

Первый запуск

Открой терминал в папке проекта, с которым хочешь работать, и набери:

bash
claude

Откроется интерактивная сессия. При первом запуске Claude Code попросит войти в аккаунт: откроется браузер, подтверждаешь, возвращаешься в терминал. Всё, можно ставить задачи.

Дальше начинается самое интересное: не переписка с ботом, а сборка продуктов и автоматизаций. Один человек с Claude Code делает то, на что раньше нужен был отдел.

Частые вопросы

Где скачать Claude Code?
Claude Code не скачивается как программа, а ставится одной командой в терминале: на Windows через PowerShell (irm https://claude.ai/install.ps1 | iex), на Mac и Linux через curl. Если нужен обычный установщик, скачай графическое приложение Claude Desktop с сайта Anthropic.
Как установить Claude Code на Windows?
Открой PowerShell и вставь команду irm https://claude.ai/install.ps1 | iex. Права администратора не нужны. Альтернатива через WinGet: winget install Anthropic.ClaudeCode.
Можно ли установить Claude Code бесплатно?
Официально Claude Code требует платного плана (от Pro за $20/мес). Попробовать бесплатно можно через open-source коннектор на бесплатных моделях, но это не полноценный Claude.
Есть ли Claude Code для Android или телефона?
Нативного приложения для Android и iOS нет. Claude Code работает на компьютере (Windows, Mac, Linux). На телефоне только через удалённый сервер, для старта это не нужно.
Как установить Claude Code в России?
Так же, как везде, одной командой. Но сначала нужен доступ к сервису (сайт заблокирован) и платный план (карта РФ напрямую не проходит). Оба вопроса решаются легально, разобрано в отдельной статье про Claude в России.
Нужен ли Node.js для установки?
Для нативной установки (команда через PowerShell или curl) Node.js не нужен. Он требуется только если ставить через npm, там нужна версия 22 и выше.
