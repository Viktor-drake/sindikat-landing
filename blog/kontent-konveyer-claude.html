Контент-конвейер на Claude: Remotion + HeyGen без монтажа и камеры

Виктор Дачников 25 июня 2026 8 минут

Claude, HeyGen и Remotion - три части одного конвейера. Claude пишет сценарий и анализирует виралы конкурентов, HeyGen генерирует говорящий аватар с озвучкой, Remotion собирает анимацию кодом. Контент выходит каждый день без съёмки и монтажа.

Камера, монтаж, дикторская работа. Это то, что раньше занимало 80% времени при создании контента. Сейчас у меня есть конвейер, где Claude закрывает большую часть этого.

Покажу как он устроен и как его настроить с нуля.

Из чего состоит конвейер

Три инструмента, каждый делает своё:

Claude - мозг конвейера. Анализирует виральные ролики конкурентов, выделяет работающие хуки, пишет сценарии под твою нишу. Без этого слоя - просто слепое копирование.

HeyGen - аватар и озвучка. Берёт текст сценария и генерирует видео с говорящим персонажем. Ты один раз создаёшь свой аватар, дальше он появляется в каждом ролике без съёмки.

Remotion - анимация кодом. Вместо After Effects - JavaScript. Claude пишет код анимации под нужный стиль, Remotion рендерит. Динамические субтитры, motion-фон, переходы - всё через код.

Главное

Не обязательно запускать все три сразу. Начни с Claude + HeyGen - это уже даёт готовые ролики без камеры. Remotion добавляй когда нужна сложная анимация.

Шаг 1: Claude анализирует конкурентов и пишет сценарий

Это отправная точка. Берёшь ссылку на вирусный ролик конкурента, отдаёшь Claude - он разбирает структуру хука, темп, CTA, и предлагает вариант под твою нишу.

code
Вот ролик конкурента: [ссылка]

Разбери его по структуре:
1. Хук (первые 3 секунды): что именно зацепило, почему работает
2. Основная часть: какой формат (список/история/демо/провокация)
3. CTA: что просят сделать и как формулируют
4. Что можно забрать в мою нишу: [твоя ниша]

После разбора напиши сценарий под мой ролик в том же формате,
но с моим углом и моей темой: [тема ролика]

Длина: 45-60 секунд озвученного текста (примерно 120-140 слов).
Формат: разбей на блоки - Хук / Основная часть / CTA.
💡

Совет

Claude умеет читать YouTube-ролики через ссылку - у него есть доступ к транскрипту. Для TikTok и Instagram отправляй текстовый транскрипт или просто описание ролика.

Шаг 2: HeyGen генерирует аватар с озвучкой

Заходи на heygen.com. Первый раз - создай свой аватар (нужно 5-минутное видео твоего лица) или используй встроенный персонаж.

  1. Создай новый Talking Photo или Video
  2. Вставь текст сценария из Claude в поле Script
  3. Выбери голос (есть русские голоса, качество приличное)
  4. Запусти генерацию - занимает 3-5 минут

На выходе - MP4 с говорящим аватаром, синхронизация губ встроена.

ℹ️

Заметка

HeyGen отдаёт тихую аудиодорожку. Если используешь видео дальше в Remotion или монтаже - нормализуй звук до -14 LUFS. В ffmpeg это одна команда: ffmpeg -i input.mp4 -af loudnorm=I=-14 output.mp4

Шаг 3: Remotion собирает финальное видео

Remotion - это библиотека, которая рендерит видео из React-компонентов. Звучит как "нужно уметь кодить", но Claude пишет весь код за тебя.

Скажи Claude в Claude Code:

code
Настрой Remotion-проект для сборки Reels.

Что нужно:
- Видео 1080x1920 (вертикальное), 30fps
- Слой 1: видео из HeyGen (аватар) - в верхней половине кадра
- Слой 2: динамические субтитры - в нижней половине (белый текст, тёмный фон)
- Слой 3: motion-фон под аватаром (градиент с анимацией или CTA-заставка)

Субтитры: получаю как JSON-массив [{start, end, text}].
Вставляй каждую фразу по таймингу, по 3-5 слов на экран.

Шрифт: системный жирный или подключи Onest из Google Fonts.

После настройки один раз - дальше просто меняешь файл субтитров и видео от HeyGen.

💡

Совет

Субтитры как JSON получаешь командой: whisper video.mp4 --output_format json --language ru (нужен Whisper от OpenAI, устанавливается через pip). Claude Code может сделать это за тебя - скажи "транскрибируй это видео и выдай субтитры JSON для Remotion".

Шаг 4: карусели тем же набором

HeyGen и Remotion - для видео. Карусели Claude Code собирает по-другому.

code
Сделай карусель из 6 слайдов по теме: [тема]

Слайды:
1. Обложка с заголовком (хук)
2-5. По одному тезису на слайд (1-2 предложения + визуальный акцент)
6. CTA-слайд

Стек: React + Tailwind, экспорт в PNG (по 1080x1350 каждый слайд).
Стиль: тёмный фон (#0a0a0a), белый текст, акцент #FF7A45.
Шрифт: Onest.

Claude Code создаёт компоненты, рендеришь через Puppeteer или просто скриншотишь в браузере.

Как выглядит день с конвейером

Утро: нашёл вирусный ролик конкурента - отдал Claude, получил сценарий.

Днём: вставил сценарий в HeyGen, запустил генерацию (5 минут), пока она идёт - пишу пост.

Вечер: Remotion собрал финальное видео с субтитрами - опубликовал.

Итого: 30-40 минут активной работы вместо нескольких часов.

Способ быстрее: отдай эту статью Claude

Скопируй ссылку на статью, открой Claude Code и напиши: "Прочитай статью https://nextgenclub.ru/blog/kontent-konveyer-claude и помоги настроить такой конвейер под мою нишу."

Он разберёт шаги и пройдёт по ним вместе с тобой.

Промпт для анализа конкурентов - скопируй и адаптируй под свой ролик: --- Вот вирусный ролик из моей ниши: [вставь ссылку или описание] Разбери его по структуре: Хук (первые 3 секунды) / Основная часть (формат: список, история, демо, провокация) / CTA. Напиши на основе разбора сценарий для моего ролика в том же формате. Моя ниша: [твоя ниша]. Тема: [тема]. Длина: 45-60 секунд (120-140 слов). Раздели на блоки: Хук / Основная часть / CTA. --- Дальше вставляй готовый сценарий в HeyGen для генерации аватара.
