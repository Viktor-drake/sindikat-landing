Контент-дашборд в Claude Code: 6 страниц + промпты под каждую

Виктор Дачников 19 июня 2026 8 минут

Вместо десяти разрозненных таблиц - один дашборд в Claude Code. Шесть страниц: хуки, аналитика, конкуренты, планировщик, календарь, тренды. Собирается за вечер-два. Даю стартовый промпт и по промпту на каждую страницу.

У меня раньше было: хуки в заметках, аналитика в таблице, конкуренты в другой таблице, идеи в третьей. Всё отдельно, всё неудобно, всё в итоге не ведётся.

Один дашборд в Claude Code решил это. Сейчас это Next.js-приложение с шестью страницами, которое я собрал сам - без найма разработчика. Ниже стартовый промпт и по промпту на каждую страницу.

Зачем один дашборд, а не таблицы

Проблема разрозненных инструментов не в самих инструментах - в переключении между ними. Когда хук и аналитика в разных местах, ты не видишь связь между «какой формат хука» и «сколько досмотрели». Всё в одном месте - видишь паттерны.

Плюс дашборд в коде - это не Google Sheets. Можно добавить любую логику: авто-подпись под ролик, спарклайн за 30 дней, авто-теги на входящие новости. В таблице это боль, в Next.js - один промпт.

Главное

Стек: Claude Code + Next.js + Tailwind + shadcn/ui, тёмная тема. Нужен базовый фронтенд-стек и доступы к данным площадок там где нужно. Собирается последовательно: сначала каркас, потом по одной странице.

Стартовый промпт: каркас дашборда

Открой новый проект в Claude Code и отдай этот промпт целиком:

code
Создай мне контент-дашборд для управления Instagram/Reels-аккаунтом.

Стек: Next.js 14 (app router), Tailwind CSS, shadcn/ui, тёмная тема (#0a0a0a фон, акцент #FF7A45).
Шрифт: Onest (Google Fonts).

Структура - 6 страниц в сайдбаре:
1. Хранилище хуков
2. Аналитика
3. Трекер конкурентов
4. Планировщик
5. Контент-календарь
6. Что в тренде

Создай:
- Базовый layout с левым сайдбаром и навигацией по 6 страницам
- Каждая страница - заглушка с заголовком и placeholder-описанием
- Адаптивный дизайн (сайдбар сворачивается на мобильных)
- Цветовой акцент на активном пункте меню

Не добавляй пока никакой логики - только визуальный каркас.

После этого у тебя будет работающая оболочка. Дальше - страница за страницей.

Страница 1: Хранилище хуков

Сюда сохраняешь залетевшие хуки из чужих роликов - транскрипт, шаблон, ниша, тип, просмотры. Потом вставляешь в свой сценарий одной кнопкой.

code
Добавь на страницу "Хранилище хуков":

Таблица с полями: текст хука, ниша (тег), тип хука (вопрос/провокация/факт/история),
просмотры источника (число), дата добавления.

Верхний блок - фильтры: по нише, по типу, сортировка по просмотрам.
Кнопка "Добавить хук" открывает модалку с формой.
У каждой строки - кнопка "Скопировать шаблон" (берёт текст хука и копирует в буфер).

Хранение: localStorage пока, потом заменим на базу.
💡

Совет

Когда смотришь рилс конкурента и видишь хороший хук - сразу сохраняй сюда. Не «потом запишу». Через неделю не вспомнишь.

Страница 2: Аналитика

Просмотры, сохранения, подписки - с динамикой, не просто числом.

code
Добавь на страницу "Аналитика":

4 карточки вверху: просмотры за 7 дней, сохранения за 7 дней, новые подписчики за 7 дней,
средний охват ролика. В каждой карточке - спарклайн (мини-график) за последние 7 точек.

Ниже - таблица роликов: название/хук, дата, просмотры, досмотры%, сохранения, комментарии.
Подсветка строк выше медианы по просмотрам (зелёный акцент).

Переключатель периода: 7 / 30 / 90 дней.

Данные пока вводятся вручную через модалку "Добавить ролик". API к платформам подключим отдельно.

Страница 3: Трекер конкурентов

Список аккаунтов + их топ-ролики за неделю автоматически.

code
Добавь на страницу "Трекер конкурентов":

Список карточек конкурентов: @username, ниша, число подписчиков, статус (активный/пауза).
Кнопка "Добавить конкурента" - форма с полями выше.

Под каждым конкурентом - аккордеон "Топ роликов этой недели" (разворачивается).
Внутри: таблица с хуком ролика, просмотрами, ссылкой.
Кнопка "Сохранить хук" - переносит хук на страницу Хранилища хуков.

Данные вводятся вручную. Позже подключим Apify для авто-сбора.

Страница 4: Планировщик

Постинг в один клик с автоматически собранной подписью.

code
Добавь на страницу "Планировщик":

Форма постинга ролика:
- Поле для загрузки видео
- Выбор площадки: Instagram / TikTok / YouTube Shorts (чекбоксы)
- Выбор хука из Хранилища (выпадающий список с поиском)
- Угол (текст, 1-2 предложения)
- CTA (выпадающий список готовых CTA: "напиши ГАЙД", "напиши КОМАНДА" и т.п.)

Кнопка "Сгенерировать подпись" - собирает текст из хука + угла + CTA.
Поле предпросмотра подписи с кнопкой "Копировать".

Статус публикаций: таблица последних 10 постов с датой и площадкой.
ℹ️

Заметка

Авто-публикацию в Instagram через официальный API можно добавить позже. На старте - дашборд готовит контент, публикуешь вручную. Это всё равно в разы быстрее чем собирать подпись каждый раз заново.

Страница 5: Контент-календарь

Месячная сетка, каждый слот - дата + площадка + хук.

code
Добавь на страницу "Контент-календарь":

Месячная сетка (7 колонок по дням недели, строки по неделям).
Каждая ячейка - слот для поста: дата, иконка площадки, первые слова хука.
Клик на ячейку - открывает модалку: дата, время, площадка (выбор), хук (выбор из Хранилища), статус (план/готово/опубликовано).

Цветовая кодировка статусов: серый/желтый/зелёный.
Кнопка "Заполнить неделю" - открывает форму где задаёшь: сколько постов в неделю, на каких площадках, Claude предлагает даты/времена по лучшим слотам (из данных Аналитики).

Страница 6: Что в тренде

AI-новости из нескольких источников, авто-теги, фильтр по полезности.

code
Добавь на страницу "Что в тренде":

Лента карточек новостей: заголовок, источник, дата, краткое описание (2-3 предложения),
тег (hook / explainer / skip - авто-присваивается Claude при добавлении).

Фильтры сверху: по тегу, по источнику, по дате (сегодня / неделя / всё).
Сортировка: по свежести / по релевантности.

Кнопка "Добавить новость" - форма: URL источника, при вставке URL автоматически
подтягивается заголовок и описание (через fetch → summary через Claude API).
Кнопка у карточки "Сделать ролик из этого" - создаёт черновик в Планировщике с этим хуком.

Источники по умолчанию: Claude.ai blog, Anthropic blog, OpenAI blog, X/Twitter trending AI,
ProductHunt AI, vc.ru AI-раздел.

Как это собирать

Не пытайся сделать всё за один раз. Схема, которая работает:

День 1: Каркас + Хранилище хуков. Начни записывать хуки сразу - это самая частоиспользуемая страница.

День 2: Аналитика + Трекер конкурентов. Внеси данные за последние 30 дней вручную - сразу увидишь паттерны.

День 3+: Планировщик, Календарь, Тренды - по одной странице когда есть время.

Нужен Claude Code, базовый фронтенд-стек (Node.js, умение запустить npm run dev), и 2-3 часа.

Дашборд в коде - это не разовый инструмент. Ты добавляешь страницы по мере роста, подключаешь реальные данные (Instagram API, Apify для конкурентов), и инструмент растёт вместе с аккаунтом.
