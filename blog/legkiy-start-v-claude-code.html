Для кого этот план

Если ты предприниматель, маркетолог, методолог, эксперт или руководитель и хочешь разобраться в Claude Code без диплома айтишника, этот план для тебя. Три шага: доступ и оплата, база по устройству инструмента, первые скиллы. После этого будет понятно, куда двигаться дальше под свою конкретную задачу.

Шаг 0. Доступ, регистрация, оплата

Работает, тысячи людей платят и пользуются. Нужно просто знать порядок действий.

Доступ к сервису. Claude.ai заблокирован в РФ, нужен инструмент обхода блокировок. Какой конкретно, лучше уточнить лично, готового универсального совета тут нет: сервисы часто меняются. Важный момент: страна VPN и страна платёжного инструмента должны совпадать. Если VPN показывает Казахстан, а карта или счёт оформлены на другую страну, сервис может заблокировать оплату или сам аккаунт. Без этого шага дальше не двигаться.

Регистрация через Google. Самый простой путь: регистрируй Claude через Google-аккаунт, которому не меньше года. У Google-аккаунта страна значения не имеет, и если регистрация проходит через него, номер телефона может вообще не понадобиться. Попробуй сначала этот вариант.

Виртуальный номер, если Google не подошёл. Российский номер (+7) Claude не принимает, нужен виртуальный номер другой страны.

Где взять: 365sms.io/claude, стоит 15-300 рублей.

Какие страны проходят лучше всего:

  • Казахстан, Грузия, Армения, Германия - самые стабильные
  • Украина, Кыргызстан - тоже работают
  • Индия, Индонезия, Бразилия - если стран СНГ нет в наличии

Берёшь номер, получаешь смс с кодом, вводишь, готово.

Регистрация. Заходишь на claude.ai, нажимаешь Sign up, вводишь почту (Gmail подходит), подтверждаешь кодом из письма, при необходимости вводишь виртуальный номер. Аккаунт создан.

Оплата. Три рабочих варианта:

  • МТС Платёжный сервис (payment.mts.ru): платишь через СБП российской картой, на почту приходят инструкции по активации, обработка около 15 минут.
  • Виртуальная карта «Плати по миру» (platipomiru.com): выпускаешь карту в евро или долларах, пополняешь рублями через СБП любого банка, конвертация мгновенная. Стоит 2990 ₽, подходит тариф для подписок (не для путешествий за 5к), первый год обслуживания бесплатно, регистрация 2 минуты через Telegram или сайт. Плюс: карта работает не только для Claude, а для любых зарубежных сервисов, оформил один раз и пользуешься дальше.
  • Помогут с оплатой: если не хочется разбираться самому, можно написать @katerina_laskovets или @eternalbliss1996, они оформят.

Какой план выбрать. Бесплатный - базовый доступ с лимитами, без Claude Code и Cowork. Pro (20$/мес) - без ограничений, свежие модели, приоритет при нагрузке. Max (100$/мес) - для серьёзной профессиональной работы и доступа к API.

Проверяй актуальные цены и условия в своём аккаунте: тарифы и работоспособность сервисов оплаты со временем меняются.

Результат

Шаг 0: у тебя есть рабочий доступ к Claude, зарегистрированный аккаунт и оплаченный тариф (Pro или выше, чтобы был доступен Claude Code).

Шаг 1. Как устроен Claude изнутри

Сначала главное отличие. Обычный чат Claude отвечает на вопросы: ты спросил, он ответил, дальше сам решаешь, что с этим делать. Claude Code устроен иначе - это агентная система. Он сам принимает решения, сам, по своей инициативе, доводит задачу до конца и стремится к нужному итоговому результату, а не просто выдаёт текст в ответ на вопрос. Именно поэтому с ним работают не как с поисковиком, а как с исполнителем, которому нужно поставить задачу и дать контекст.

Три среды Claude. Их три, и путать их не стоит:

  • Claude.ai (чат) - обычный веб-интерфейс для разовых вопросов, синхронизируется между устройствами.
  • Claude Code - самая функциональная среда, работает с папками и файлами напрямую, держит в памяти контекст до 1 миллиона токенов, агентная система из пункта выше. Именно про неё этот план.
  • Claude Cowork - упрощённая версия Claude Code, подходит новичкам: та же логика работы с файлами и задачами, но интерфейс проще и порог входа ниже.

Ключевая логика Claude Code: проекты организуются через папки, каждая папка - это отдельный контекст, отдельная сессия под свою задачу. Не смешивай всё в одну кучу.

Модели. Три уровня: Haiku (быстрая и дешёвая, для простого), Sonnet (баланс, закрывает примерно 80% рабочих задач), Opus (мощная, меньше ошибается, для сложных и важных вещей). Уровень рассуждений (effort) обычно достаточно оставить на среднем значении, вручную трогать нужно редко.

База знаний и файл памяти. Прежде чем работать, Claude Code полезно дать базу знаний о твоём проекте. Создай на рабочем столе папку «Claude Code» и положи туда всю информацию, какая есть: заметки, документы, черновики, описание бизнеса или задачи. Дальше попроси Claude прочитать всё это и на основе прочитанного самому создать файл памяти CLAUDE.md, вручную заводить этот файл не нужно.

Дальше Claude Code постоянно обращается к этому файлу и работает с твоими файлами именно на его основе. Эта база знаний, по сути, фундамент, на котором дальше строится вся инфраструктура твоей работы в Claude: чем полнее и понятнее база сейчас, тем точнее и стабильнее результат в будущем.

⚠️

Внимание

Частые ошибки новичков:

  • Кириллица в путях к папкам: лучше называть папки латиницей.
  • Пароли и ключи, вставленные прямо в переписку с Claude: так делать нельзя никогда.
  • Отсутствие скриншотов при попытке объяснить, что не так на сайте или в интерфейсе: показать проще и надёжнее, чем описать словами.
  • Устаревшее приложение, которое не обновили: потом удивляются, почему что-то не работает.

Режимы разрешений: сколько свободы дать Claude. По умолчанию Claude Code спрашивает разрешение перед каждым действием: прочитать файл можно без вопроса, а вот изменить файл или выполнить команду - только после твоего "да". Переключаются режимы клавишей Shift+Tab прямо в сессии, текущий режим виден внизу экрана.

  • Ask Permissions (по умолчанию) - спрашивает разрешение на каждое действие с файлами и командами. Лучше всего для старта и для чувствительных задач, пока не понимаешь, как Claude поведёт себя в твоей папке.
  • Accept edits (автопринятие правок) - сам применяет правки файлов и простые файловые команды (создать папку, переместить, скопировать), не переспрашивая каждый раз. Удобно, когда правишь код или документ и потом сверяешь результат разом, а не по шагам.
  • Plan mode (режим плана) - Claude только читает и исследует, ничего не меняет, а в конце показывает план действий. Хорошо подходит, чтобы сначала понять, что он собирается делать, и только потом разрешить.
  • Auto mode (автономный режим) - почти не спрашивает разрешений, но фоновая модель-проверяющий следит, чтобы действия не выходили за рамки задачи. Экспериментальный режим, доступен не на всех тарифах и моделях. Подходит для длинных задач, когда надоело подтверждать каждый шаг.
  • Bypass permissions (пропустить все проверки) - вообще не спрашивает ничего. Использовать только в изолированной среде (контейнер, отдельная виртуальная машина), где Claude физически не может навредить твоему компьютеру. Для обычной работы на своём ноутбуке не подходит.
💡

Совет

Для первого дня достаточно Ask Permissions и Plan mode. Accept edits и Auto mode включай, когда уже понимаешь, как Claude ведёт себя в твоей папке, а Bypass permissions не трогай вообще, если не работаешь в отдельном контейнере.

Как разговаривать с Claude Code. Несколько рабочих фраз на первое время:

  1. «Изучи эту папку и объясни, что здесь находится»
  2. «Составь план, как решить задачу, но пока ничего не меняй»
  3. «Предложи 3 варианта простыми словами»
  4. «Проверь, нет ли рисков, если мы это изменим»
  5. «Сделай минимальную версию, которую можно проверить»
  6. «Объясни, что ты изменил, человеческим языком»
  7. «Если что-то неясно, сначала задай мне уточняющие вопросы»

Хороший старт - это не «сразу собрать сложного агента», а провести Claude Code по шагам: контекст, план, маленькое изменение, проверка, следующий шаг.

Шаг 2. Базовые скиллы

Важно понимать: Claude из коробки, без единого скилла, коннектора или MCP-сервера, это примерно 5% от того, что инструмент умеет на самом деле. Разница между «голым» Claude и Claude, в который поставлены нужные инструменты, огромная.

Скилл - это просто файл с инструкцией. Дальше Claude использует его сам, без пересказа контекста заново. По сути, скилл - это запомненная последовательность успешных действий: один раз довели задачу до результата, зафиксировали, дальше инструмент повторяет её сам.

Уровень 1. Ставим сразу, без вопросов

  • security-guard - страхует от случайного слива паролей, токенов, ключей в переписку. Работает фоново, спрашивает подтверждение перед рискованными операциями.
  • skill-selector - сам определяет, какой скилл нужен под задачу, и запускает его. Снимает вопрос «а что вообще ставить».
  • RTK (Rust Token Killer) - сокращает вывод команд на 60-90%, экономит токены и деньги на длинных сессиях. Открытый исходный код: github.com/rtk-ai/rtk.

Уровень 2. Рабочие скиллы под конкретные задачи

  • prompt-engineer - превращает голосовую заметку или сырую идею в структурированный промпт. Полезен, если печатать длинные ТЗ не хочется.
  • content-pro - пишет посты, тексты, лендинги под твой стиль и нишу.

Уровень 3. Когда уже освоился

  • llm-council - прогоняет решение через совет из 5 ИИ-советников, полезен, когда есть реальный размен вариантов («X или Y») и не получается решить самому.
  • GSD (Get Shit Done) - фреймворк для серьёзной разработки и проектов: планирование по фазам, проверка перед запуском, контроль результата. Открытый исходный код: github.com/gsd-build/get-shit-done.
  • autonomous-deploy - деплой на Vercel без единой команды в консоли, для тех, кто уже работает с сайтами.
  • claude-mem - память между сессиями, закрывает главную боль: Claude забывает контекст между разговорами. Открытый исходный код: github.com/thedotmack/claude-mem.

Формула, которая работает почти всегда: контекст → план → маленькое изменение → проверка → следующий шаг. Не пытайся поставить и освоить всё за один вечер, три уровня выше - это порядок, а не список на сегодня.

Скиллы под конкретно твою нишу и задачу можно и нужно искать самому: они лежат в открытом доступе на GitHub и в других источниках, ставятся так же просто, как из этого списка. Единственное правило: перед установкой смотри, что внутри, откуда скилл и кто его написал, не ставь вслепую первое попавшееся.

Скиллы-файлы из этого списка (security-guard, skill-selector, prompt-engineer, content-pro, llm-council, autonomous-deploy) собрал одним архивом, можешь сразу скачать и положить в свою папку скиллов: Скачать claude-code-bazovye-skilly.zip. RTK, GSD и claude-mem - это отдельные open-source инструменты, ставятся по ссылкам на GitHub выше.
