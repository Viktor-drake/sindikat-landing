5 MCP-серверов для Claude Code: обновлённый набор на осень 2026

Виктор Дачников 21 сентября 2026 6 минут

Что ты получишь, прочитав эту статью

  • пять серверов, которые реально меняют работу Claude Code
  • точную команду установки для каждого, проверенную по npm
  • честную пометку, где нужен платный ключ, а где нет
  • что поменялось с июньского набора и почему

MCP это способ дать Claude Code руки: доступ к браузеру, поиску, чужим сайтам и генерации картинок. Без них он умеет только то, что лежит у тебя в папке.

Набор, который я называл в июне, за лето сдвинулся. Два пункта из пяти поменялись, и об этом честно ниже.

1. Perplexity: поиск в интернете прямо из терминала

Claude перестаёт быть отрезанным от сегодняшнего дня. Он ищет сам, не выходя из диалога, и приносит ответ со ссылками.

bash
claude mcp add perplexity -- npx -y @perplexity-ai/mcp-server

Нужен ключ Perplexity API, он платный. Это единственный пункт в списке, где без денег не обойтись совсем.

2. Playwright: полный контроль над браузером

Claude открывает страницы, кликает, заполняет формы и сам тестирует то, что собрал. Для вайбкодинга это переход от «написал код» к «проверил, что работает».

bash
claude mcp add playwright -- npx -y @playwright/mcp@latest

Бесплатно, ключ не нужен.

3. Firecrawl: любая ссылка становится текстом

Кидаешь адрес, получаешь чистое содержимое страницы без мусорного HTML, рекламы и меню. Удобно, когда надо скормить Claude чужую документацию или разбор конкурента.

bash
claude mcp add firecrawl --env FIRECRAWL_API_KEY=ваш_ключ -- npx -y firecrawl-mcp

Есть бесплатный тариф, его хватает на пробу.

4. Higgsfield: тридцать с лишним моделей картинок и видео

Один сервер подключает Claude сразу к большому набору генеративных моделей, и не надо держать подписки на каждую по отдельности.

Ставится не из npm, а из репозитория robonuggets/higgsfield-skill.

ℹ️

Заметка

В июньском наборе на этом месте был Glif. Higgsfield занял его место, потому что даёт заметно больше моделей в одном подключении. Если у вас уже стоит Glif, менять срочно не нужно, оба рабочие.

5. Chrome DevTools: Claude видит ваш настоящий браузер

Самый недооценённый пункт. Claude получает доступ к тому Chrome, который открыт у вас: читает консоль, смотрит сеть, дебажит живую страницу.

bash
claude mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest

Главное

Не ставьте все пять сразу. Каждый подключённый сервер добавляет описания своих инструментов в контекст каждой сессии, и набор из десятка серверов съедает заметную часть окна ещё до вашего первого слова. Ставьте под задачу.

Что поменялось с июня

Два пункта. Glif уступил место Higgsfield из-за числа моделей в одном подключении. Chrome MCP заменился на Chrome DevTools MCP: это разные вещи, второй сделан командой Chrome и работает с протоколом отладки напрямую.

Остальные три пункта за лето не сдвинулись, и это само по себе показатель: Perplexity, Playwright и Firecrawl закрывают задачи, которые никуда не делись.

Частые вопросы

Сколько это стоит?
Playwright и Chrome DevTools бесплатны. Firecrawl имеет бесплатный тариф. Perplexity требует платный ключ.
Где посмотреть, что уже подключено?
Команда claude mcp list покажет установленные серверы.
Можно ли поставить всё и не думать?
Технически да, но контекст не бесплатный. Лишние серверы забирают место, которое пригодилось бы вашему коду.
Чем MCP отличается от скилла?
Скилл это инструкция, как делать. MCP это доступ к внешней системе. Скилл учит, MCP даёт руки.
