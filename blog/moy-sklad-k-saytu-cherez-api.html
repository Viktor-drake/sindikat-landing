Подключение «Мой склад» к сайту через API

Виктор Дачников 27 июля 2026 6 минут

🟡 Средний уровень - нужен аккаунт «Мой склад» с доступом администратора, программирование не требуется

Что ты получишь, прочитав эту статью

  • Поймёшь, зачем связывать сайт со складом напрямую, а не вести остатки руками
  • Получишь токен доступа к «Мой склад» и подключишь его к сайту через Claude
  • Настроишь автоматическую подгрузку остатков и цен: списал приход - на витрине обновилось
  • Узнаешь, что можно тянуть кроме остатков и где подводные камни

Собрал интернет-магазин на Claude, залил каталог - и дальше начинается рутина: списал товар в «Мой склад», зашёл на сайт, поправил карточку руками. На двух товарах терпимо, на двухстах - невозможно. Решение - связать сайт со складом напрямую, чтобы остатки подтягивались сами.

Главное

У «Мой склад» есть официальный JSON API: даёшь Claude токен доступа, он подключает сайт к твоему складу. После этого актуальные остатки и цены подтягиваются автоматически - списал из прихода, на витрине обновилось. Никакого ручного редактирования карточек.

Зачем это вообще нужно

Пока каталог и остатки живут в двух местах - в «Мой склад» и на сайте отдельно - они неизбежно расходятся. Клиент видит товар в наличии, оформляет заказ, а его на самом деле нет. Или наоборот: товар есть, но на сайте висит «нет в наличии», и продажа не случилась.

«Мой склад» - это твой единственный источник правды по остаткам. Логично, чтобы сайт брал цифры оттуда, а не хранил свою копию, которую надо синхронизировать вручную.

Как это работает

«Мой склад» отдаёт данные через официальный JSON API (версия 1.2). Это стандартный механизм: сайт по защищённому запросу спрашивает у склада «сколько сейчас такого-то товара», склад отвечает актуальной цифрой. Авторизация - по токену доступа, привязанному к твоему аккаунту.

Claude умеет работать с таким API так же, как с любым другим: ты даёшь ему токен, он пишет связку между сайтом и складом. Тебе не нужно разбираться в устройстве API - достаточно получить токен и передать его Claude.

Шаг 1. Получить токен доступа

  1. Зайди в свой аккаунт «Мой склад» под администратором.
  2. В настройках найди раздел для разработчиков / доступ к API (в интерфейсе он в разделе настроек профиля и обмена данными).
  3. Сгенерируй токен доступа к JSON API. Это длинная строка - по сути пароль, который заменяет логин/пароль при обращениях к API.

Токен - это учётные данные. Храни его как пароль: не публикуй в коде сайта, не отправляй в чаты. При настройке Claude кладёт его в защищённое место (переменную окружения), а не в открытый код.

Шаг 2. Передать токен Claude и подключить

Дальше это делается в диалоге. Открываешь проект сайта в Claude Code и говоришь примерно так:

«Вот токен доступа к моему складу в "Мой склад" [токен]. Подключи мой интернет-магазин к нему через JSON API, чтобы остатки товаров подтягивались с моего склада автоматически.»

Claude разбирается в структуре API «Мой склад», сопоставляет товары на сайте с товарами на складе (обычно по артикулу) и настраивает подгрузку остатков. Здесь важно, чтобы артикулы на сайте и в складе совпадали - это ключ, по которому связываются карточки.

Шаг 3. Проверить, что остатки живые

После подключения проверь на реальном примере: спиши товар из прихода в «Мой склад» и посмотри, обновилась ли цифра на сайте. Если да - связка работает, дальше остатки живут сами.

Что ещё можно тянуть кроме остатков

Через тот же API доступны не только остатки:

  • Цены - если ведёшь цены в «Мой склад», сайт может брать их оттуда, чтобы не править в двух местах
  • Карточки товаров - название, описание, характеристики, если основной каталог у тебя в складе
  • Изображения - можно подтягивать фото товаров, привязанные к позициям

На старте разумно подключить только остатки (это самое болезненное), а цены и карточки добавить, когда базовая связка обкатана.

⚠️

Внимание

Про частоту обновления. Обычно сайт запрашивает остатки не в реальном времени на каждый клик покупателя, а по расписанию - раз в несколько минут или при загрузке страницы. Мгновенная синхронизация «секунда в секунду» технически возможна, но для большинства магазинов избыточна и создаёт лишнюю нагрузку. Claude поможет выбрать разумный интервал под твой поток заказов.

Подводные камни

  • Артикулы должны совпадать. Если на сайте товар с одним артикулом, а в складе с другим (или артикула нет вообще) - связать их не по чему. Наведи порядок с артикулами до подключения.
  • Токен даёт доступ ко всему складу. Токен - это ключ ко всем данным аккаунта. Если делаешь сайт для клиента, обсуди, кто хранит токен и на чьём аккаунте склад.
  • Тариф «Мой склад». Доступ к API есть на большинстве тарифов, но на самом базовом может быть ограничен - проверь свой перед настройкой.

Частые вопросы

Нужно ли программировать, чтобы это настроить?
Нет. Токен получаешь мышкой в интерфейсе «Мой склад», связку пишет Claude. Разбираться в устройстве API самому не нужно.
Это работает только с сайтом на Claude или с любым?
Механизм универсальный - «Мой склад» отдаёт данные любому сайту, который умеет обращаться к его API. Но если сайт собран на Claude, вся настройка делается в том же диалоге, без отдельного разработчика.
Что будет, если товара нет на складе?
Сайт покажет актуальный остаток - ноль или «нет в наличии», в зависимости от того, как настроена карточка. Именно в этом смысл: витрина всегда отражает реальный склад.
Безопасно ли давать Claude токен?
Токен хранится в защищённой переменной окружения, а не в открытом коде сайта, который видят посетители. Общие правила те же, что с любым паролем: не публиковать, не пересылать в мессенджерах.
А обратно - с сайта в склад - данные идут?
Да, API двусторонний: при оформлении заказа на сайте можно создавать заказ в «Мой склад», чтобы он сразу списывал товар. Это следующий уровень автоматизации после подгрузки остатков.
