Claude из коробки умный, но это инструмент общего назначения. Скиллы превращают его в заточенного специалиста: под твои тексты, твои сайты, твои договоры, твою аналитику. Я собрал свой рабочий набор в один архив, чтобы можно было скачать и пользоваться.

Главное

Скилл это папка с инструкцией для Claude. Кладёшь её в свою папку скиллов, и Claude сам подхватывает нужный под задачу. Один раз настроил, дальше работает без объяснений.

Что такое скилл

Это набор правил и шагов для конкретной задачи, иногда со скриптами. Без скилла ты каждый раз объясняешь Claude заново, как написать пост в твоём стиле или собрать сайт. Со скиллом он уже знает методологию: какие хуки, какая структура, какие проверки. Это как нанять узкого специалиста, только он живёт в одной папке и работает мгновенно.

Скачать набор

Весь мой рабочий набор скиллов одним архивом:

Скачать nextgen-skills-pack.zip

Внутри: папки скиллов, README с установкой и описание каждого скилла. Все мои личные ключи и данные вырезаны и заменены на плейсхолдеры, вписываешь свои.

Установка за 2 минуты

  1. Скачай и распакуй архив
  2. Скопируй папки из skills/ в свою папку скиллов Claude Code:
code
Windows: C:\Users\ВАШ_ПОЛЬЗОВАТЕЛЬ\.claude\skills\
Mac:     ~/.claude/skills/
  1. Перезапусти Claude Code, скиллы подхватятся сами
💡

Совет

Ставь почти весь набор. Скиллы не мешают друг другу, а Claude сам берёт нужный под задачу. Чем больше у тебя в арсенале, тем меньше ты объясняешь руками.

Что внутри набора

Контент и тексты

  • content-pro: пишет посты, которые дочитывают и репостят, без воды
  • humanizer: вычищает «робота» из текста, чтобы тебя не спалили на нейросети
  • prompt-engineer: превращает сумбурное голосовое в чёткий промпт с результатом с первого раза
  • content-radar: показывает, что залетело у конкурентов, и даёт готовые идеи под тебя

Соцсети, видео и аудио

  • reels-content: заголовки, описания и хэштеги для рилсов и Shorts сразу под все площадки
  • reels-viewer: разбирает любой Reels или TikTok по ссылке: о чём, как сделан, чем цепляет
  • youtube-analyzer: выжимает суть из YouTube за минуту по реальному транскрипту
  • whisper-transcribe: превращает видео и аудио в текст и субтитры прямо у тебя на компе, бесплатно

Сайты и дизайн

  • high-end-visual-design: дизайн, который выглядит на миллион, а не на бесплатный шаблон
  • design-taste-frontend: лендинги с характером, которые не спутать с типовой нейронкой
  • redesign-existing-projects: берёт старый сайт и поднимает до премиум-уровня
  • kinolanding: кинематографичный лендинг с AI-видео, уровень студии за вечер
  • autonomous-deploy: сам выкатывает сайт в интернет, без танцев с настройками

Картинки

  • image-pro: генерит картинки уровня ChatGPT с первого раза, без мучений с промптами

Бизнес и операции

  • contract-generator: собирает грамотный договор ИП за минуты вместо похода к юристу
  • nda-onboarding: оформляет NDA и доступы подрядчику, чтобы спать спокойно
  • google-workspace: создаёт и заполняет Google Доки и Таблицы прямо из чата
  • zoom-transcripts: превращает часовой созвон в выжимку с договорённостями за минуту
  • autoresearch: сам улучшает код по заданной метрике, пока ты занят другим

ИИ-советники и мета

  • llm-council: прогоняет твоё решение через совет из 5 ИИ-экспертов и выдаёт усиленный вердикт
  • skill-selector: сам подбирает, какие скиллы взять под задачу
  • security-guard: страхует, чтобы ты случайно не слил пароли и ключи

Обязательно поставь ещё

Это не скиллы, а плагины, ставятся отдельно, но без них набор неполный:

  • claude-mem - память между сессиями. Claude перестаёт забывать: помнит твои проекты, решения и контекст. Установка: /plugin install claude-mem. Подробнее: github.com/thedotmack/claude-mem
  • GSD (Get Shit Done) - фреймворк для серьёзной разработки. Ведёт по фазам: обсуждение, план, исполнение, проверка, публикация. Незаменим, когда задача больше «один файл за 30 минут». Установка: npx @opengsd/gsd-core@latest. Подробнее: github.com/open-gsd/gsd-core
  • Базовые скиллы Anthropic для документов - работа с Word, Excel, PowerPoint и PDF прямо в Claude. Установка: /plugin marketplace add anthropics/skills, затем /plugin install document-skills@anthropic-agent-skills. Подробнее: github.com/anthropics/skills
ℹ️

Заметка

Часть скиллов требует своих ключей и настроек. Открой файл скилла и впиши своё там, где стоят метки в квадратных скобках, например ВСТАВЬ_СВОЙ_КЛЮЧ. Это нормально, ключи у каждого свои.

Частые вопросы

Это бесплатно?
Да, архив можно скачать и поставить бесплатно. Часть скиллов работает на платных сервисах (например генерация картинок), там нужен свой ключ.
Нужно уметь программировать?
Нет. Скилл это текстовая инструкция, ты просто кладёшь папку на место и пользуешься обычными словами.
Мои данные в безопасности?
Скиллы работают локально у тебя. В архиве нет ни моих, ни чьих-либо ключей, только плейсхолдеры под твои собственные.
