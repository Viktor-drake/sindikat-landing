279 субагентов для Claude Code: как поставить нужный отдел и не сжечь контекст

Что это такое

Agency Agents это папка с текстовыми файлами на гитхабе. Каждый файл это отдельный специалист для Claude Code: инженер, дизайнер, маркетолог, аналитик, тестировщик, юрист.

Внутри файла обычный markdown с двумя ключевыми полями в начале: имя агента и описание, когда его звать. Дальше идёт сам инструктаж: опыт специалиста, порядок работы, формат результата.

Разница с «промптом на все случаи» простая. Это не один агент, который притворяется то дизайнером, то юристом. Это разные специалисты с разными инструкциями, и Claude Code подключает того, чья роль подходит к задаче.

Главное

Agency Agents превращает Claude Code из одного универсального помощника в набор узких специалистов. Ставить нужно не весь набор, а только тот отдел, который нужен сегодня: полная установка постоянно занимает часть контекста и делает это ещё до твоего первого сообщения.

Скрытая цена: около 17 тысяч токенов

Вот то, о чём обзоры обычно молчат.

Claude Code, чтобы выбрать подходящего субагента, должен знать про всех установленных. Поэтому имена и описания всех агентов попадают в контекст каждой сессии. Не тексты инструкций целиком, только имена и описания, но их много.

Я замерил это на клоне репозитория: сложил поля name и description у всех 279 агентов и получил 68 345 символов. Для русско-английского текста это примерно 17 тысяч токенов.

Ключевое здесь не сама величина, а момент. Эти токены расходуются до того, как ты напишешь первое слово. Просто за факт установки. И в каждой новой сессии заново.

⚠️

Внимание

В README репозитория как способ для Claude Code предложена команда ./scripts/install.sh --tool claude-code. Она ставит всех 279 агентов. То есть дефолтный, рекомендованный самим проектом путь и есть тот, который стоит 17 тысяч токенов на сессию.

Правильный способ: ставить отдел, а не всё подряд

У установщика есть флаг --division. Он ставит только выбранные отделы, и тогда в Claude работают лишь те специалисты, которые нужны сегодня.

Сначала забираем репозиторий:

bash
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents

Смотрим, что вообще есть, ничего не устанавливая:

bash
./scripts/install.sh --list teams

Проверяем план установки на сухом прогоне. Он печатает, что будет сделано, и выходит, не записав ни одного файла:

bash
./scripts/install.sh --division engineering --tool claude-code --dry-run

Если план устраивает, ставим по-настоящему. Несколько отделов перечисляются через запятую:

bash
./scripts/install.sh --division engineering,testing --tool claude-code

Иногда не нужен и отдел целиком, а нужны два конкретных специалиста. Тогда вместо --division берём --agent:

bash
./scripts/install.sh --agent frontend-developer,backend-architect --tool claude-code

Агенты лягут в ~/.claude/agents/. После этого в сессии достаточно попросить Claude подключить нужную роль, и он подхватит специалиста.

💡

Совет

Поставь --link вместо копирования, и агенты будут симлинками на репозиторий. Тогда git pull в папке репозитория обновляет твой набор, и не надо переустанавливать вручную.

Если терминал не нравится

У проекта есть отдельное десктопное приложение (macOS, Linux, Windows). Оно показывает весь состав списком и ставит выбранных агентов в Claude Code, Cursor, Codex и ещё несколько инструментов, а потом обновляет их. Это отдельный репозиторий того же автора, на нём около 560 звёзд против 153 тысяч у основного, то есть обкатан он заметно меньше. Для первого знакомства без терминала подходит, но команды выше дают больше контроля.

Чего ждать не стоит

Честные ограничения, чтобы не было разочарования.

Это markdown-файлы с инструкциями, а не программы. Субагент не даёт Claude новых умений и не подключает внешние сервисы: за подключения отвечают MCP-серверы, про них есть отдельный разбор в статье про 5 MCP-серверов для Claude Code.

Качество внутри набора неровное. Инженерных агентов 64 и они проработаны лучше всего, а в медицине их три. Отдел с тремя агентами это скорее заявка на тему, чем готовая команда.

Имя агента не гарантирует результат. «Юрист» здесь это роль и стиль работы, а не юридическая ответственность, и проверять выводы всё равно придётся.

И главное: чем больше агентов установлено, тем хуже выбор. Claude выбирает специалиста по описаниям, и когда их 279, вероятность взять не того выше, чем когда их 9. Узкий набор работает не только дешевле, но и точнее.

Частые вопросы

Это бесплатно?
Да. Лицензия MIT, можно использовать в коммерческих проектах, менять файлы под себя и держать свою версию.
Нужно ли знать программирование?
Нет. Установка это две команды в терминале, а дальше обычный разговор с Claude Code. Если Claude Code ещё не стоит, начни с инструкции по установке Claude Code.
Чем субагенты отличаются от скиллов?
Субагент это роль со своим порядком работы, скилл это готовая процедура под конкретную задачу. Про скиллы есть отдельный разбор в статье про библиотеку скиллов Claude.
Сколько отделов ставить сразу?
Один или два под текущую работу. Каждый следующий отдел добавляет описания в контекст каждой сессии и ухудшает точность выбора.
Можно ли переписать агента под себя?
Да, это обычный markdown. Меняешь описание и инструктаж, и агент начинает работать по твоему процессу. При установке через --link правки удобнее держать в форке.
