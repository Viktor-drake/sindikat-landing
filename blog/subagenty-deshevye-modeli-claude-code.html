Субагенты на дешёвых моделях: как Claude Code перестаёт жечь лимиты на поиск

Виктор Дачников 24 сентября 2026 6 минут

Что ты получишь, прочитав эту статью

  • почему поиск по проекту по умолчанию идёт на самой дорогой модели
  • что изменилось в версии 2.1.198 и почему это важно
  • схема «оркестра»: кто планирует, кто пишет код, кто ищет
  • три готовых субагента, которые можно скопировать к себе
  • где эта схема не сэкономит

Когда Claude Code ищет по проекту, читает файлы и правит мелочи, всё это по умолчанию крутит та же модель, что и главная сессия. Сидишь на Opus, значит и поиск по папкам идёт на Opus. Это как нанять главного архитектора и отправить его сортировать папки.

Что изменилось в 2.1.198

Раньше встроенный агент поиска Explore всегда работал на Haiku, самой быстрой и дешёвой модели. С версии 2.1.198 он наследует модель основного разговора. На Claude API наследуемая модель ограничена Opus: если разговор идёт на модели выше, Explore работает на Opus.

Решение понятное: поиск на сильной модели точнее. Но если ты считаешь лимиты, каждый «найди, где это лежит» теперь стоит как задача для Opus.

Схема оркестра

РольМодельЧто делает
Дирижёрглавная сессия, Opusпланирует, раздаёт задачи, проверяет результат
РазработчикSonnetпишет и правит код по готовому плану
РазведчикHaikuищет по проекту, читает файлы, собирает контекст

Главная модель не тратит себя на рутину. Она получает от разведчика короткую выжимку вместо сотни прочитанных файлов и принимает решения.

Как настроить: одна строка

Субагент в Claude Code это markdown-файл с заголовком. Модель задаётся полем model:

  • haiku, sonnet, opus, fable: псевдоним модели
  • полный идентификатор, например claude-sonnet-5
  • inherit: та же модель, что у главного разговора

Файлы кладутся в .claude/agents/ внутри проекта (только для него) или в ~/.claude/agents/ (для всех твоих проектов). Claude Code подхватывает их сам через несколько секунд.

ℹ️

Заметка

Команда /agents с версии 2.1.198 больше не открывает мастер создания. Она только напоминает, что субагента можно попросить создать у самого Claude или написать файл руками. Проще всего первое: «создай субагента-разведчика, только чтение, модель haiku».

Есть и второй способ: переменная окружения CLAUDE_CODE_SUBAGENT_MODEL задаёт модель субагентам по умолчанию, если модель не указана другим способом.

Три готовых субагента

Разведчик на Haiku

markdown
---
name: scout
description: Ищет по проекту и собирает контекст. Используй, когда нужно найти, где что лежит, или прочитать много файлов перед решением.
tools: Read, Grep, Glob
model: haiku
---

Ты разведчик. Найди то, о чём просят, и верни короткую выжимку: пути к файлам,
номера строк и две-три фразы, что там происходит. Код не меняй. Если не нашёл,
так и скажи и перечисли, где искал.

Разработчик на Sonnet

markdown
---
name: builder
description: Пишет и правит код по готовому плану. Используй, когда план уже утверждён и нужно его реализовать.
tools: Read, Edit, Write, Grep, Glob, Bash
model: sonnet
---

Ты разработчик. Реализуй ровно тот план, который тебе передали, без лишних улучшений.
После изменений запусти проверки проекта и верни список изменённых файлов и результат
проверок.

Ревьюер на главной модели

markdown
---
name: reviewer
description: Проверяет изменения перед сдачей. Используй после того, как разработчик закончил.
tools: Read, Grep, Glob, Bash
model: inherit
---

Ты ревьюер. Проверь изменения на ошибки, пропущенные случаи и расхождение с планом.
Верни список конкретных замечаний с файлом и строкой. Если замечаний нет, так и скажи.

Ревьюер намеренно на inherit: проверка это как раз то место, где сильная модель окупается.

Где это не сэкономит

  • Мелкая задача целиком. Если всё дело в одной правке, передача субагенту стоит

дороже самой правки.

  • Сложный поиск. Когда искать надо не строку, а смысл («где у нас нарушается логика

оплаты»), дешёвая модель может промахнуться. Такой поиск оставь главной модели.

  • Без проверки. Результат дешёвых моделей главная сессия обязана проверять. Если

пропустить этот шаг, экономия лимитов превратится в переделки.

Частые вопросы

Это официальная функция?
Да, поле model у субагентов описано в документации Claude Code.
Сколько реально экономит?
Зависит от того, какая доля работы у тебя приходится на поиск и чтение файлов. Чем больше проект и чем чаще агент ищет, тем заметнее разница.
Не упадёт ли качество?
На поиске и сборе контекста почти нет. На решениях и проверке может, поэтому они остаются на главной модели.
Работает на подписке, а не на API?
Да, субагенты и выбор модели работают в Claude Code независимо от способа оплаты.
Можно ли поставить агентов сразу во все проекты?
Да, положи файлы в ~/.claude/agents/.
