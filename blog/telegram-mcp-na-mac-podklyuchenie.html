Telegram MCP, это коннектор, после которого Claude умеет работать с твоим Telegram напрямую: читать чаты, искать переписки, отправлять сообщения и файлы, отвечать в топиках, работать с папками и контактами. Не «покажи скриншот и я прочитаю», а буквально залезть в чат и сделать дело.

На Mac установка ловила одну систематическую проблему: у части участников сессия Telegram умирала через пару минут после входа, иногда попутно выбивая официальный Telegram Desktop. Разбирались две недели вместе с одним из участников клуба, перебрали и исключили активность, дубли процессов, флаг аккаунта, VPN. Причина оказалась в «отпечатке» клиента: библиотека, на которой собран коннектор, по умолчанию представляется Telegram как приложение Telegram Desktop, но с параметрами устройства, которых не существует. Для антифрода это выглядит как подделка, и он отзывал свежие сессии.

В этой сборке отпечаток компьютера подставляется автоматически, отдельным скриптом, перед первым входом. После фикса сессия у тестировавшего участника отработала больше трёх недель без единой ошибки.

Что внутри архива

  • Сам сервер (94 функции: сообщения, чаты, папки, контакты, топики, черновики, боты)
  • Скрипт, который сам определяет модель компьютера, версию macOS и версию Telegram и не даёт сломать уже рабочую сессию, если запустить его повторно
  • Скрипт входа в Telegram (один раз, номер и код, пароль двухфакторки вводится скрыто)
  • Скилл для Claude, чтобы он сам знал все 94 функции и не отвечал «такого инструмента нет», когда на самом деле просто не подгрузил его в контекст
  • Пошаговый README внутри архива, версия ниже короче, вся диагностика неполадок там

Пользуешься Codex вместо (или вместе с) Claude Code? Codex подключает MCP-серверы иначе, обычный режим не примет. Тебе нужна отдельная сборка с тем же содержимым, но другим транспортом:

Скачать telegram-mcp-codex.zip

Ставить обе сразу на одну и ту же сессию Telegram нельзя: Telegram отзывает ключ, если сессия используется из двух мест одновременно. Если нужны и Claude Code, и Codex, в README codex-сборки есть шаг, как один демон обслуживает оба сразу.

Установка по шагам

1. Распакуй архив в удобное место, не в папку Documents: macOS не даст терминалу прав на неё. Подойдёт домашняя папка: ~/telegram-mcp.

2. Собери окружение. В терминале, из папки с архивом:

code
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

3. Заполни настройки. Скопируй .env.example в .env и впиши TELEGRAM_API_ID и TELEGRAM_API_HASH: свои с my.telegram.org или те, что выдали в клубе.

4. Определи отпечаток компьютера. Обязательный шаг, до входа:

code
.venv/bin/python scripts/detect_fingerprint.py

Скрипт сам подставит модель Mac, версию системы и версию Telegram. Если уже стоит рабочая сессия, он откажется что-либо менять и объяснит почему.

5. Войди в Telegram, один раз:

code
.venv/bin/python scripts/session_string_generator.py

Номер, код из Telegram, пароль двухфакторки. После входа не нажимай «Завершить все сессии», это убьёт только что созданную сессию.

6. Запусти демон:

code
chmod +x start_daemon.sh && ./start_daemon.sh

7. Подключи к Claude Code. В .mcp.json проекта:

json
{
  "mcpServers": {
    "telegram-mcp-v2": {
      "type": "sse",
      "url": "http://127.0.0.1:8765/sse"
    }
  }
}

Перезапусти сессию Claude: MCP подключается только при старте.

8. Поставь скилл. Скопируй папку skill/telegram-assistant из архива в ~/.claude/skills/. Без этого шага Claude видит только те функции, которыми уже пользовался, и может честно, но неправильно сказать, что отправки сообщений «нет»: на деле она просто не подгружена в контекст.

Проверка: «отправь мне в избранное тестовое сообщение». Если пришло, всё готово.

Если что-то пошло не так

Полная диагностика в README внутри архива, но три причины закрывают почти все случаи:

  • Сессия умирает за пару минут: пропущен шаг 4 или он был сделан после входа, а не до. Порядок обязателен.
  • «Not authorized» сразу после успешного входа: нажали «Завершить все сессии» после логина. Входи заново, больше не завершай.
  • Claude говорит, что нужной функции нет: не поставлен скилл (шаг 8) или сессия Claude не перезапущена после установки.
ℹ️

Заметка

Один демон, один компьютер. Не запускай вторую копию с той же сессией «на всякий случай»: Telegram считает это признаком угона аккаунта и отзывает ключ у обеих копий сразу.

Дальше это просто работает: Claude читает переписки, ищет нужные сообщения, отвечает за тебя в чатах, где ты попросишь, скачивает и отправляет файлы. Один из практичных примеров использования: коннектор берёт на себя мониторинг профильных чатов и подготовку ответов лидам, без ручного пролистывания ленты.
