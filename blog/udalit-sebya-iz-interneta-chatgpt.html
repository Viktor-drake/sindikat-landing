Убрать себя из интернета за три промпта: ChatGPT против брокеров данных

Виктор Дачников 29 июня 2026 6 минут

Брокеры данных продают твой адрес, телефон, соцсети - без твоего ведома. ChatGPT с тремя промптами находит где ты засвечен, пишет письма на удаление и через Agent Mode сам их отправляет. Плюс ставит еженедельный напоминатель.

Я спросил ChatGPT что он знает обо мне. Ответ меня напугал.

Он нашёл мой адрес на трёх сайтах, которые я никогда не слышал. Номер телефона на двух. Фото из социальных сетей, которые я думал давно удалил. Это не взлом - это легальный бизнес брокеров данных. Они собирают публичную информацию и продают её.

Вот как убрать себя из этих баз за три промпта.

Промпт 1: найди всё что есть обо мне

Открой ChatGPT (нужен Plus или Pro для веб-поиска) и вставь:

code
Найди в открытых источниках всё что есть обо мне в интернете.

Имя: [твоё имя]
Email: [твой основной email]
Username(s): [твои никнеймы в соцсетях]
Город: [твой город]

Ищи на сайтах-брокерах данных (Spokeo, Whitepages, BeenVerified, Radaris, MyLife и аналогах), в результатах поиска, в открытых базах.

Составь список: сайт - какая именно информация о тебе там есть.

ChatGPT пройдётся по открытым источникам и вернёт список. Где-то будет имя и город, где-то телефон и адрес, где-то история переездов. Сохрани этот список - он нужен для второго промпта.

ℹ️

Заметка

Российские брокеры данных тоже существуют: GetContact, Truecaller, сайты-агрегаторы судебных решений, архивы объявлений. Добавь в запрос "включая российские источники" если нужен полный охват.

Промпт 2: напиши письма на удаление

Вставь список из первого промпта и добавь:

code
Вот сайты где найдена моя информация:
[вставь список из первого промпта]

Напиши готовое письмо-заявку на удаление для каждого сайта.

В каждом письме:
- Обращение к оператору сайта
- Ссылка на страницу с моими данными (если нашёл)
- Требование удалить все мои персональные данные
- Ссылка на право субъекта данных (GDPR для европейских, CCPA для американских, ФЗ-152 для российских)
- Мой email для подтверждения удаления

Оформи каждое письмо отдельным блоком с заголовком [Сайт: название].

Ты получишь готовые письма под каждый сайт - с нужными формулировками, ссылками на законы и требованиями. Остаётся только отправить.

💡

Совет

Большинство западных брокеров данных обязаны ответить в течение 30-45 дней (требование GDPR/CCPA). Российские - в течение 30 дней по ФЗ-152. Сохрани дату отправки каждого письма.

Промпт 3: Agent Mode отправляет сам

Если у тебя ChatGPT Pro - включи Agent Mode (иконка компьютера в боковом меню). Это режим где ChatGPT управляет браузером вместо тебя.

code
Используй Agent Mode.

Вот список сайтов откуда нужно запросить удаление моих данных:
[список сайтов]

Для каждого сайта:
1. Зайди на страницу удаления данных (обычно /privacy, /optout, /data-removal или форма в footer)
2. Найди форму запроса на удаление
3. Заполни форму моими данными: [имя], [email]
4. Отправь запрос
5. Сделай скриншот подтверждения

Если на сайте нет формы - сохрани email и я отправлю письмо вручную.

ChatGPT сам открывает браузер, ищет формы, заполняет их и отправляет. Ты наблюдаешь и подтверждаешь каждый шаг. На 10-15 сайтов уходит 15-20 минут вместо нескольких часов ручной работы.

Главное

Agent Mode требует ChatGPT Pro (~$20 в месяц). Если его нет - промпт 2 всё равно работает: у тебя готовые письма, остаётся только отправить их вручную с нужного email.

Бонус: еженедельный мониторинг

Базы данных пополняются. Новая утечка, новый сайт с твоими данными - и всё начинается заново. Один промпт ставит автоматическое напоминание:

code
Создай повторяющееся напоминание: каждое воскресенье в 11:00.

Текст напоминания:
"Проверить новые утечки данных. Запустить промпт: найди в открытых источниках всё что есть обо мне - [имя], [email], [username]. Сравни с прошлым списком, нашли что-то новое?"

Если у тебя нет доступа к созданию напоминаний - дай мне точную команду для Google Calendar или Apple Reminders.
💡

Совет

Раз в квартал повторяй полный цикл всех трёх промптов. Удалённые данные иногда возвращаются - брокеры восстанавливают базы из новых источников.

Сколько это работает

Крупные западные брокеры (Spokeo, BeenVerified, Whitepages) удаляют данные по запросу в течение 2-4 недель. Мелкие сайты - по-разному, некоторые игнорируют. Российские ресурсы хуже реагируют на GDPR, лучше на ФЗ-152.

Реалистичный результат через месяц: 60-80% сайтов удалят твои данные. Остальные - повторный запрос или жалоба в Роскомнадзор/надзорный орган страны сайта.

Это не идеальная защита, но это лучшее что можно сделать за час без найма юриста.

Частые вопросы

Это законно и это точно не взлом?
Речь не про взлом. Брокеры данных это легальный бизнес: они собирают публичную информацию и продают её. А ты пользуешься своим правом субъекта персональных данных и требуешь их удалить. Основания разные в зависимости от страны сайта: GDPR для европейских, CCPA для американских, ФЗ-152 для российских.
Нужна ли платная подписка ChatGPT?
Для поиска утечек нужен Plus или Pro, потому что необходим веб-поиск. Agent Mode, который сам заполняет формы на сайтах, доступен только на Pro. Но без него схема тоже работает: второй промпт всё равно выдаёт готовые письма, останется отправить их вручную.
Сколько сайтов реально удалят мои данные?
Реалистично 60-80 процентов за месяц. Крупные западные брокеры (Spokeo, BeenVerified, Whitepages) удаляют за 2-4 недели. Мелкие сайты реагируют по-разному, некоторые просто игнорируют. С остальными остаётся повторный запрос или жалоба в Роскомнадзор либо в надзорный орган страны сайта.
Работает ли это с российскими источниками?
Да, но их надо запросить отдельно: допиши в промпт «включая российские источники». Речь про GetContact, Truecaller, агрегаторы судебных решений, архивы объявлений. На ФЗ-152 они реагируют лучше, чем на GDPR.
Один раз почистился и всё?
Нет. Базы пополняются, и удалённые данные иногда возвращаются: брокеры восстанавливают их из новых источников. Поставь еженедельное напоминание на проверку и раз в квартал прогоняй полный цикл всех трёх промптов.
